Serialize and deserialize a binary tree

The trick isn’t JSON — it’s preserving shape when nulls matter and leaves aren’t evenly balanced.

1. Problem statement & explanation

Design an algorithm to serialize a binary tree to a string and deserialize that string back into a tree. There is no prescribed format — you only have to guarantee the round trip: deserialize(serialize(root)) must produce a tree structurally identical to root, with the same values in the same positions.

The one thing that makes this Hard: a binary tree's shape is not recoverable from its values alone. The trees 1→left 2 and 1→right 2 both contain the values {1, 2} and both have a preorder traversal of 1, 2. So any correct format must encode absence as well as presence. Every viable answer boils down to one of two choices: emit explicit markers for missing children, or emit positions that make absence implicit.

That framing is what the interviewer is listening for. Say it in the first minute and the rest of the hour is implementation. Miss it and you will produce a codec that passes on balanced trees and silently corrupts skewed ones.

1.1 Input / output

Signature

Worked examples

example 1 — the standard case
Tree:            1
                / \
               2   3
                  / \
                 4   5

serialize(root) = "1,2,#,#,3,4,#,#,5,#,#"     (preorder, '#' = absent child)
Token count     = 11 = 2n + 1 for n = 5 nodes.

Read it as: 1, then left subtree (2 with two absent children),
then right subtree (3, its left 4 with two absent, its right 5 with two absent).
example 2 — why markers are mandatory
Tree A:   1        Tree B:   1
         /                     \
        2                       2

Values:   {1, 2} for both.  Preorder values: "1,2" for both.
With markers:  A -> "1,2,#,#,#"      B -> "1,#,2,#,#"
                     ^ 2 is the LEFT child      ^ 2 is the RIGHT child

Without markers the two trees are indistinguishable. This example is the
whole reason the problem is not trivial.
example 3 — degenerate inputs
root = None            -> "#"              -> None
root = [1]             -> "1,#,#"          -> single node
root = [1,2,null,3]    -> "1,2,3,#,#,#,#"  -> left-skewed chain of 3
root = [-1000]         -> "-1000,#,#"      -> negatives need a sign, so '-'
                                              must not be the delimiter

Constraints to state back

  • 0 ≤ number of nodes ≤ 10^4 — the empty tree is legal, and 10⁴ nodes in a straight line means recursion depth 10⁴. Python's default limit is 1000; the JVM default stack fails somewhere in the low tens of thousands. This is a real constraint, not a theoretical one.
  • -1000 ≤ node.val ≤ 1000 — values are small but signed, so the format must tolerate a leading -.
  • Values may repeat, so no format may rely on values being unique (this rules out preorder+inorder pairing).
  • Output is a single string; any encoding is acceptable as long as your own deserialize can read it. Nothing is promised about interoperability with other implementations unless you ask.

2. Open questions & clarifications

  • Does the format need to be human-readable or interoperable? If a different language must read it, I would use JSON or protobuf and discuss schema. If it is opaque and only my own pair of functions touches it, I can pick the most compact encoding.
  • Is this a general binary tree or a BST? Big difference: a BST is fully determined by its preorder sequence, so no null markers are needed at all — the value bounds tell you where each subtree ends. Roughly halves the output.
  • What is the value type and range? Integers let me use a simple delimiter. Arbitrary strings mean the payload could itself contain the delimiter, so I need escaping or length-prefixing. This is the classic injection bug in a serializer.
  • Can values repeat? If they are guaranteed unique, preorder + inorder is a valid (if inferior) encoding. If not, that approach is simply wrong.
  • How deep can the tree be? Decides recursion vs explicit stack/queue. At 10⁴ nodes, a skewed tree overflows Python's recursion limit outright.
  • Is output size a constraint? Are we writing to disk or over a network at scale? That is what motivates bit-packing the structure separately from the values.
  • Do nodes carry payloads beyond val? Parent pointers, sibling links, or extra fields change what “identical” means.
  • Must deserialize handle malformed or truncated input? Production answer: yes, validate and fail loudly. Interview answer: ask, then state the assumption you are coding to.
  • Must the two functions be stateless? A codec that stashes the tree in an instance field and returns a lookup key technically passes the round-trip test and is a well-known cheat. Confirm it is out of scope — and mention that you know it exists.
  • Is streaming required? Can I hold the whole string in memory, or must I write incrementally to a socket?

2.1 Suggestions to the candidate

  • Do not start writing a traversal. Start by stating the shape problem: “values alone do not determine the tree, so I must encode absence.” Draw the two-node counterexample from 1.1. This is the insight being graded and it takes 45 seconds.
  • Do not open with the optimal encoding. Describe the fixed-position array encoding first — it is the format most people picture — then demolish it yourself with the skewed-tree argument. Being the one who finds your own solution's flaw is a strong signal.
  • Write the format down before writing code. Literally on the board: "1,2,#,#,3,4,#,#,5,#,#". Then write the parser against that string. Nearly all bugs here are format/parser disagreements, and a written example prevents them.
  • Say the symmetry rule out loud. “deserialize must consume tokens in exactly the order serialize produced them — value, then left subtree, then right subtree.” If you write left before right in one and right before left in the other, the tree comes back mirrored on some inputs and correct on others, which is the worst kind of bug.
  • Do not use an index variable you forget to advance. Use a real iterator, queue, or stream so consumption is structural. Shared mutable indices across recursive calls are where candidates lose ten minutes.
  • Choose the delimiter deliberately and justify it. A comma works because values are integers; say “if values were arbitrary strings I would length-prefix instead of delimit.”
  • Raise the recursion depth issue before the interviewer does. “10⁴ nodes in a chain is 10⁴ stack frames, so for production I would use the iterative BFS version.” Then show it if time allows.
  • Test the empty tree and the single node explicitly. They are the two inputs that break naive implementations, and they cost one line each to verify.

3. Brute-force approach

Encode by position instead of by markers. Give the root index 0 and store the children of index i at 2i+1 and 2i+2 — the standard heap layout. Emit every slot from 0 up to the largest occupied index, writing # for the empty ones. Deserialization is then a single linear pass wiring index i to 2i+1 and 2i+2.

  1. Walk the tree, recording slots[index] = val for each node at its heap index.
  2. Emit slots[0 … max_index], using # for gaps.
  3. To decode: materialise one node per non-# token, then for each index i attach nodes[2i+1] as its left child and nodes[2i+2] as its right.
The fatal flaw — find it before your interviewer does

The largest index at depth d is 2^(d+1) - 2. So the output length is governed by tree height, not node count. A right-skewed chain of just 20 nodes emits over a million slots. The stated limit of 10⁴ nodes allows a chain of height 10⁴, which needs 2^10000 slots — a number with about 3000 digits. Worse, in Java, C++ and Rust the index 2i+1 overflows a 64-bit integer past depth 62, so the encoding is not merely slow, it is unrepresentable.

from typing import Dict, List, Optional


class TreeNode:
    def __init__(self, val: int = 0) -> None:
        self.val = val
        self.left: Optional[TreeNode] = None
        self.right: Optional[TreeNode] = None


def serialize_brute(root: Optional[TreeNode]) -> str:
    """Complete-array (heap index) encoding: children of i live at 2i+1, 2i+2.

    Output length is 2^height, NOT O(n). Correct, but unusable on skewed trees.
    """
    if root is None:
        return "#"

    slots: Dict[int, int] = {}

    def place(node: Optional[TreeNode], i: int) -> None:
        if node is None:
            return
        slots[i] = node.val
        place(node.left, 2 * i + 1)
        place(node.right, 2 * i + 2)

    place(root, 0)
    width = max(slots) + 1                 # 2^height - 1 in the worst case
    return ",".join(str(slots[i]) if i in slots else "#" for i in range(width))


def deserialize_brute(data: str) -> Optional[TreeNode]:
    """One pass: build every node, then wire i -> 2i+1, 2i+2."""
    tokens = data.split(",")
    if tokens == ["#"]:
        return None

    nodes: List[Optional[TreeNode]] = [
        None if t == "#" else TreeNode(int(t)) for t in tokens
    ]
    for i, node in enumerate(nodes):
        if node is None:
            continue
        left, right = 2 * i + 1, 2 * i + 2
        if left < len(nodes):
            node.left = nodes[left]
        if right < len(nodes):
            node.right = nodes[right]
    return nodes[0]

#[derive(Debug)]
pub struct TreeNode {
    pub val: i32,
    pub left: Option<Box<TreeNode>>,
    pub right: Option<Box<TreeNode>>,
}

impl TreeNode {
    pub fn new(val: i32) -> Self {
        TreeNode { val, left: None, right: None }
    }
}

/// Complete-array (heap index) encoding: children of i live at 2i+1, 2i+2.
///
/// Output length is 2^height, NOT O(n). The index also overflows u64 past
/// depth 62, so this encoding cannot even represent a deep chain.
pub fn serialize_brute(root: &Option<Box<TreeNode>>) -> String {
    fn place(node: &Option<Box<TreeNode>>, i: u64, slots: &mut HashMap<u64, i32>) {
        if let Some(n) = node {
            slots.insert(i, n.val);
            // Depth > 62 overflows here -- a hard limit of this format.
            place(&n.left, 2 * i + 1, slots);
            place(&n.right, 2 * i + 2, slots);
        }
    }

    if root.is_none() {
        return "#".to_string();
    }
    let mut slots: HashMap<u64, i32> = HashMap::new();
    place(root, 0, &mut slots);

    let width = slots.keys().copied().max().unwrap() + 1;
    (0..width)
        .map(|i| match slots.get(&i) {
            Some(v) => v.to_string(),
            None => "#".to_string(),
        })
        .collect::<Vec<_>>()
        .join(",")
}

/// Rebuild by index. Nodes are built into a flat Vec, then linked bottom-up
/// so each child can be moved into its parent exactly once.
pub fn deserialize_brute(data: &str) -> Option<Box<TreeNode>> {
    let tokens: Vec<&str> = data.split(',').collect();
    if tokens == ["#"] {
        return None;
    }

    let mut nodes: Vec<Option<Box<TreeNode>>> = tokens
        .iter()
        .map(|t| {
            if *t == "#" {
                None
            } else {
                Some(Box::new(TreeNode::new(t.parse().expect("bad token"))))
            }
        })
        .collect();

    // Reverse order guarantees both children are final before the parent.
    for i in (0..nodes.len()).rev() {
        if nodes[i].is_none() {
            continue;
        }
        let left = if 2 * i + 1 < nodes.len() { nodes[2 * i + 1].take() } else { None };
        let right = if 2 * i + 2 < nodes.len() { nodes[2 * i + 2].take() } else { None };
        let parent = nodes[i].as_mut().unwrap();
        parent.left = left;
        parent.right = right;
    }
    nodes[0].take()
}
import java.util.HashMap;
import java.util.Map;
import java.util.StringJoiner;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class BruteCodec {

    /**
     * Complete-array (heap index) encoding: children of i live at 2i+1, 2i+2.
     * Output length is 2^height, NOT O(n), and the index overflows long
     * past depth 62 -- so deep chains cannot even be represented.
     */
    public String serialize(TreeNode root) {
        if (root == null) return "#";

        Map<Long, Integer> slots = new HashMap<>();
        place(root, 0L, slots);

        long max = 0;
        for (long key : slots.keySet()) max = Math.max(max, key);

        StringJoiner out = new StringJoiner(",");
        for (long i = 0; i <= max; i++) {
            Integer v = slots.get(i);
            out.add(v == null ? "#" : v.toString());
        }
        return out.toString();
    }

    private void place(TreeNode node, long i, Map<Long, Integer> slots) {
        if (node == null) return;
        slots.put(i, node.val);
        place(node.left, 2 * i + 1, slots);    // overflows past depth 62
        place(node.right, 2 * i + 2, slots);
    }

    /** One pass: build every node, then wire i -> 2i+1, 2i+2. */
    public TreeNode deserialize(String data) {
        String[] tokens = data.split(",");
        if (tokens.length == 1 && tokens[0].equals("#")) return null;

        TreeNode[] nodes = new TreeNode[tokens.length];
        for (int i = 0; i < tokens.length; i++) {
            if (!tokens[i].equals("#")) {
                nodes[i] = new TreeNode(Integer.parseInt(tokens[i]));
            }
        }
        for (int i = 0; i < nodes.length; i++) {
            if (nodes[i] == null) continue;
            if (2 * i + 1 < nodes.length) nodes[i].left = nodes[2 * i + 1];
            if (2 * i + 2 < nodes.length) nodes[i].right = nodes[2 * i + 2];
        }
        return nodes[0];
    }
}

class BruteCodec {
public:
    // Complete-array (heap index) encoding: children of i live at 2i+1, 2i+2.
    // Output length is 2^height, NOT O(n), and the index overflows int64
    // past depth 62 -- so deep chains cannot even be represented.
    std::string serialize(TreeNode* root) {
        if (root == nullptr) return "#";

        std::unordered_map<std::int64_t, int> slots;
        place(root, 0, slots);

        std::int64_t max = 0;
        for (const auto& kv : slots) max = std::max(max, kv.first);

        std::ostringstream out;
        for (std::int64_t i = 0; i <= max; ++i) {
            if (i) out << ',';
            auto it = slots.find(i);
            if (it == slots.end()) out << '#';
            else out << it->second;
        }
        return out.str();
    }

    // One pass: build every node, then wire i -> 2i+1, 2i+2.
    TreeNode* deserialize(const std::string& data) {
        std::vector<std::string> tokens;
        std::istringstream in(data);
        std::string tok;
        while (std::getline(in, tok, ',')) tokens.push_back(tok);
        if (tokens.size() == 1 && tokens[0] == "#") return nullptr;

        std::vector<TreeNode*> nodes(tokens.size(), nullptr);
        for (std::size_t i = 0; i < tokens.size(); ++i) {
            if (tokens[i] != "#") nodes[i] = new TreeNode(std::stoi(tokens[i]));
        }
        for (std::size_t i = 0; i < nodes.size(); ++i) {
            if (nodes[i] == nullptr) continue;
            if (2 * i + 1 < nodes.size()) nodes[i]->left = nodes[2 * i + 1];
            if (2 * i + 2 < nodes.size()) nodes[i]->right = nodes[2 * i + 2];
        }
        return nodes[0];
    }

private:
    void place(TreeNode* node, std::int64_t i,
               std::unordered_map<std::int64_t, int>& slots) {
        if (node == nullptr) return;
        slots[i] = node->val;
        place(node->left, 2 * i + 1, slots);    // overflows past depth 62
        place(node->right, 2 * i + 2, slots);
    }
};

3.2 Complexity

Time O(2^h)

Where h is the tree height. Balanced: 2^h ≈ n, so effectively O(n) and perfectly fine. Skewed: h = n, giving O(2^n) — unusable beyond ~25 nodes.

Space O(2^h)

The emitted string dominates. Plus O(h) recursion. And a hard representational ceiling at depth 62 in any fixed-width-integer language.

Why this is not the final answer

We are paying to describe positions that contain nothing. But a traversal already visits children in a fixed order — so instead of encoding where each node is, we can encode whether each child slot is occupied, in traversal order. That is one marker per absent child, and a tree with n nodes has exactly n+1 absent child slots. Total tokens: 2n+1. Linear, and independent of shape.

4. Optimised approach

Key insight: a preorder traversal that emits an explicit marker for every null child is a self-delimiting encoding. Reading it back needs no lookahead and no index arithmetic: read a token; if it is the marker, the subtree is empty; otherwise make a node, then recursively build its left subtree and then its right subtree from the same token stream. The recursion structure of the reader mirrors the writer exactly, which is why it works.

  1. Serialize: if the node is null, emit # and return. Otherwise emit its value, then recurse left, then recurse right. Join with a delimiter.
  2. Deserialize: split into tokens and consume them through a single shared cursor (an iterator, queue, or stream — not a copied index).
  3. Pop one token. If it is #, return null.
  4. Otherwise create the node, set node.left = build(), then node.right = build(), and return it. The order of those two lines must match the order in serialize.
The invariant to say out loud

Every call to build() consumes exactly the tokens that the matching call to walk() produced — one complete subtree's worth — and leaves the cursor pointing at the next sibling's first token. That is why no separators, lengths, or backtracking are needed. A tree with n nodes has 2n child slots of which n-1 are filled, so exactly n+1 markers are emitted: 2n+1 tokens total.

4.1 Code — Python, Rust, Java, C++

from typing import Iterator, List, Optional

NULL = "#"


class Codec:
    """Preorder DFS with an explicit marker for every absent child."""

    def serialize(self, root: Optional[TreeNode]) -> str:
        out: List[str] = []

        def walk(node: Optional[TreeNode]) -> None:
            if node is None:
                out.append(NULL)           # absence is DATA, not a gap
                return
            out.append(str(node.val))
            walk(node.left)                # order here must match `build`
            walk(node.right)

        walk(root)
        return ",".join(out)

    def deserialize(self, data: str) -> Optional[TreeNode]:
        # A single iterator IS the cursor: every recursive call advances the
        # same stream, so no index has to be threaded through or returned.
        tokens: Iterator[str] = iter(data.split(","))

        def build() -> Optional[TreeNode]:
            token = next(tokens)
            if token == NULL:
                return None
            node = TreeNode(int(token))
            node.left = build()            # same order as `walk`
            node.right = build()
            return node

        return build()


# Round-trip check:
#   Codec().deserialize(Codec().serialize(root))  ==  root  (structurally)
# Note: recursion depth is O(height). For a 10^4-node chain this exceeds
# Python's default limit of 1000 -- use the iterative codec in 4.3.
const NULL: &str = "#";

/// Preorder DFS with an explicit marker for every absent child.
pub fn serialize(root: &Option<Box<TreeNode>>) -> String {
    fn walk(node: &Option<Box<TreeNode>>, out: &mut Vec<String>) {
        match node {
            None => out.push(NULL.to_string()),   // absence is DATA
            Some(n) => {
                out.push(n.val.to_string());
                walk(&n.left, out);               // order must match `build`
                walk(&n.right, out);
            }
        }
    }

    let mut out: Vec<String> = Vec::new();
    walk(root, &mut out);
    out.join(",")
}

/// The iterator IS the cursor: each recursive call advances the same stream.
fn build<'a, I>(tokens: &mut I) -> Option<Box<TreeNode>>
where
    I: Iterator<Item = &'a str>,
{
    let token = tokens.next()?;                   // stream exhausted => None
    if token == NULL {
        return None;
    }
    let val: i32 = token.parse().expect("malformed token");
    let left = build(tokens);                     // same order as `walk`
    let right = build(tokens);
    Some(Box::new(TreeNode { val, left, right }))
}

pub fn deserialize(data: &str) -> Option<Box<TreeNode>> {
    let mut tokens = data.split(',');
    build(&mut tokens)
}
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

public class Codec {

    private static final String NULL = "#";

    /** Preorder DFS with an explicit marker for every absent child. */
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        walk(root, sb);
        return sb.toString();
    }

    private void walk(TreeNode node, StringBuilder sb) {
        if (sb.length() > 0) sb.append(',');
        if (node == null) {
            sb.append(NULL);                       // absence is DATA
            return;
        }
        sb.append(node.val);
        walk(node.left, sb);                       // order must match build()
        walk(node.right, sb);
    }

    /** The deque IS the cursor: every recursive call polls the same stream. */
    public TreeNode deserialize(String data) {
        Deque<String> tokens =
                new ArrayDeque<>(Arrays.asList(data.split(",")));
        return build(tokens);
    }

    private TreeNode build(Deque<String> tokens) {
        String token = tokens.poll();              // null when exhausted
        if (token == null || token.equals(NULL)) {
            return null;
        }
        TreeNode node = new TreeNode(Integer.parseInt(token));
        node.left = build(tokens);                 // same order as walk()
        node.right = build(tokens);
        return node;
    }
}
#include <sstream>
#include <string>

class Codec {
public:
    // Preorder DFS with an explicit marker for every absent child.
    std::string serialize(TreeNode* root) {
        std::ostringstream out;
        walk(root, out);
        return out.str();
    }

    // The stream IS the cursor: every recursive call reads the same
    // istringstream, so no index has to be threaded through.
    TreeNode* deserialize(const std::string& data) {
        std::istringstream in(data);
        return build(in);
    }

private:
    // Space-separated so operator>> tokenises for free. The trailing
    // space is harmless.
    void walk(TreeNode* node, std::ostringstream& out) {
        if (node == nullptr) {
            out << "# ";                           // absence is DATA
            return;
        }
        out << node->val << ' ';
        walk(node->left, out);                     // order must match build()
        walk(node->right, out);
    }

    TreeNode* build(std::istringstream& in) {
        std::string token;
        if (!(in >> token) || token == "#") {      // exhausted or marker
            return nullptr;
        }
        TreeNode* node = new TreeNode(std::stoi(token));
        node->left = build(in);                    // same order as walk()
        node->right = build(in);
        return node;
    }
};

4.2 Complexity

Time O(n) each way

Each node is written once and read once. Exactly 2n+1 tokens are produced, independent of shape — a balanced tree and a straight chain of the same size cost the same.

Space O(n) output, O(h) stack

The string is O(n). Recursion is O(h) frames: O(log n) balanced, but O(n) = 10⁴ for a chain, which is the one weakness of this version.

Edge cases this version already handles

None → "#" → None. Single node → "1,#,#". Negative values survive because the delimiter is , and not -. Duplicate values are fine because nothing is keyed on value. Left-only and right-only children are distinguished by marker position — the whole point of example 2.

4.3 Variant: iterative BFS codec (no recursion)

Same token economy, zero stack depth. Serialize level by level with a queue, pushing both children of every real node — including the null ones, which become markers when dequeued. Deserialize with a second queue: dequeue a parent, take the next two tokens as its children, and enqueue whichever are real. This is the version to reach for when the tree may be 10⁴ nodes deep, and it is also the format that reads most naturally to a human.

The subtlety that bites people

Emit markers only for the children of nodes that exist. Do not enqueue the children of a null — that is precisely the mistake that turns this back into the exponential encoding from section 3. Done correctly the output is still exactly 2n+1 tokens.

from collections import deque


class BfsCodec:
    """Level-order codec. No recursion, so tree depth is irrelevant."""

    def serialize(self, root: Optional[TreeNode]) -> str:
        if root is None:
            return NULL

        out: List[str] = []
        queue = deque([root])
        while queue:
            node = queue.popleft()
            if node is None:
                out.append(NULL)
                continue
            out.append(str(node.val))
            queue.append(node.left)        # children of a REAL node only
            queue.append(node.right)
        return ",".join(out)

    def deserialize(self, data: str) -> Optional[TreeNode]:
        tokens = data.split(",")
        if tokens[0] == NULL:
            return None

        root = TreeNode(int(tokens[0]))
        queue = deque([root])
        i = 1
        while queue and i < len(tokens):
            node = queue.popleft()
            # The next two tokens are exactly this node's two children.
            for side in ("left", "right"):
                if i >= len(tokens):
                    break
                token = tokens[i]
                i += 1
                if token != NULL:
                    child = TreeNode(int(token))
                    setattr(node, side, child)
                    queue.append(child)
        return root

/// Level-order codec. No recursion, so tree depth is irrelevant.
///
/// `Rc<RefCell<..>>` is used here because BFS needs to hold a handle to a
/// parent while still being able to mutate it later -- the one case where
/// the owned `Box` tree is genuinely awkward.
pub type Link = Option<Rc<RefCell<RcTreeNode>>>;

pub struct RcTreeNode {
    pub val: i32,
    pub left: Link,
    pub right: Link,
}

pub fn serialize_bfs(root: Link) -> String {
    if root.is_none() {
        return "#".to_string();
    }

    let mut out: Vec<String> = Vec::new();
    let mut queue: VecDeque<Link> = VecDeque::new();
    queue.push_back(root);

    while let Some(slot) = queue.pop_front() {
        match slot {
            None => out.push("#".to_string()),
            Some(node) => {
                let n = node.borrow();
                out.push(n.val.to_string());
                queue.push_back(n.left.clone());   // children of a REAL node
                queue.push_back(n.right.clone());
            }
        }
    }
    out.join(",")
}

pub fn deserialize_bfs(data: &str) -> Link {
    let tokens: Vec<&str> = data.split(',').collect();
    if tokens[0] == "#" {
        return None;
    }

    let root = Rc::new(RefCell::new(RcTreeNode {
        val: tokens[0].parse().expect("bad token"),
        left: None,
        right: None,
    }));

    let mut queue: VecDeque<Rc<RefCell<RcTreeNode>>> = VecDeque::new();
    queue.push_back(Rc::clone(&root));
    let mut i = 1usize;

    while let Some(parent) = queue.pop_front() {
        // The next two tokens are exactly this node's two children.
        for side in 0..2 {
            if i >= tokens.len() {
                break;
            }
            let token = tokens[i];
            i += 1;
            if token == "#" {
                continue;
            }
            let child = Rc::new(RefCell::new(RcTreeNode {
                val: token.parse().expect("bad token"),
                left: None,
                right: None,
            }));
            if side == 0 {
                parent.borrow_mut().left = Some(Rc::clone(&child));
            } else {
                parent.borrow_mut().right = Some(Rc::clone(&child));
            }
            queue.push_back(child);
        }
    }
    Some(root)
}
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.StringJoiner;

public class BfsCodec {

    private static final String NULL = "#";

    /** Level-order codec. No recursion, so tree depth is irrelevant. */
    public String serialize(TreeNode root) {
        if (root == null) return NULL;

        StringJoiner out = new StringJoiner(",");
        // ArrayDeque rejects nulls, so LinkedList is used deliberately here.
        Deque<TreeNode> queue = new java.util.LinkedList<>();
        queue.add(root);

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            if (node == null) {
                out.add(NULL);
                continue;
            }
            out.add(Integer.toString(node.val));
            queue.add(node.left);          // children of a REAL node only
            queue.add(node.right);
        }
        return out.toString();
    }

    public TreeNode deserialize(String data) {
        String[] tokens = data.split(",");
        if (tokens[0].equals(NULL)) return null;

        TreeNode root = new TreeNode(Integer.parseInt(tokens[0]));
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);

        int i = 1;
        while (!queue.isEmpty() && i < tokens.length) {
            TreeNode node = queue.poll();
            // The next two tokens are exactly this node's two children.
            if (i < tokens.length && !tokens[i].equals(NULL)) {
                node.left = new TreeNode(Integer.parseInt(tokens[i]));
                queue.add(node.left);
            }
            i++;
            if (i < tokens.length && !tokens[i].equals(NULL)) {
                node.right = new TreeNode(Integer.parseInt(tokens[i]));
                queue.add(node.right);
            }
            i++;
        }
        return root;
    }
}
#include <queue>
#include <sstream>
#include <string>
#include <vector>

class BfsCodec {
public:
    // Level-order codec. No recursion, so tree depth is irrelevant.
    std::string serialize(TreeNode* root) {
        if (root == nullptr) return "#";

        std::ostringstream out;
        std::queue<TreeNode*> q;
        q.push(root);
        bool first = true;

        while (!q.empty()) {
            TreeNode* node = q.front();
            q.pop();
            if (!first) out << ',';
            first = false;
            if (node == nullptr) {
                out << '#';
                continue;
            }
            out << node->val;
            q.push(node->left);            // children of a REAL node only
            q.push(node->right);
        }
        return out.str();
    }

    TreeNode* deserialize(const std::string& data) {
        std::vector<std::string> tokens;
        std::istringstream in(data);
        std::string tok;
        while (std::getline(in, tok, ',')) tokens.push_back(tok);
        if (tokens.empty() || tokens[0] == "#") return nullptr;

        TreeNode* root = new TreeNode(std::stoi(tokens[0]));
        std::queue<TreeNode*> q;
        q.push(root);

        std::size_t i = 1;
        while (!q.empty() && i < tokens.size()) {
            TreeNode* node = q.front();
            q.pop();
            // The next two tokens are exactly this node's two children.
            if (i < tokens.size() && tokens[i] != "#") {
                node->left = new TreeNode(std::stoi(tokens[i]));
                q.push(node->left);
            }
            ++i;
            if (i < tokens.size() && tokens[i] != "#") {
                node->right = new TreeNode(std::stoi(tokens[i]));
                q.push(node->right);
            }
            ++i;
        }
        return root;
    }
};
Time O(n) each way

Same 2n+1 tokens as the preorder codec. No asymptotic difference — this is purely about which resource you spend.

Space O(n) output, O(w) queue

w is the maximum tree width, up to n/2 for a balanced tree but only O(1) for a chain — the exact inverse of the recursive version's profile.

Which one would I ship?

Preorder for interviews and for deep or unknown-shape trees, converted to an explicit stack if depth is a risk. BFS when the output should be readable by a human (levels line up) or when the tree is known to be deep and narrow. State the trade in one line: DFS costs O(height), BFS costs O(width) — pick against the shape you expect.

5. Follow-up discussion if time permits

  • Serialize a BST with no null markers at all. Preorder plus value bounds is enough: while rebuilding, a token belongs to the current subtree only if it lies inside (low, high). Output drops from 2n+1 tokens to n — a genuine ~50% saving that comes purely from the extra structural guarantee. Great answer to “can you do better?”
  • Make it as compact as possible. Separate structure from payload: emit 2n+1 bits of shape information (1 = node, 0 = null) plus n packed values. With |val| ≤ 1000 that is 11 bits per value, so ~13 bits per node total versus ~40 bits for the comma-separated text. This is exactly how succinct tree representations work.
  • Why not preorder + inorder? It rebuilds the tree only when all values are distinct, needs a value→index map, and emits 2n tokens for no benefit. Worth naming and rejecting with the duplicate-value counterexample.
  • N-ary trees. Emit each node's child count before its children (length-prefixing), or use a closing marker per node. Length-prefixing is more robust because it survives truncation detection.
  • Arbitrary string values. The delimiter can now appear inside the payload. Either escape it or, better, length-prefix each field (5:hello). This is the bug class that produces real CVEs in home-grown serializers.
  • Truncated or malicious input. A hostile string can drive unbounded allocation or recursion. Defend with a declared node count, a depth cap, and an explicit “stream ended early” error rather than returning a partial tree.
  • Schema evolution. If nodes gain a field next quarter, an unversioned positional format breaks every stored blob. Add a version byte, or move to protobuf/Thrift where field tags make additions backward compatible. Strong signal for anything infra-adjacent.
  • Streaming, tree too large for memory. Preorder is already streamable in both directions: write tokens as you walk, and build incrementally with an explicit stack while reading. BFS is not — it needs the queue resident.
  • Verifying the round trip. Property-based testing: generate random trees, assert deserialize(serialize(t)) is structurally equal to t, and assert serialize is deterministic. Mentioning property tests rather than three hand-written cases reads as production experience.
  • What does “good enough” look like here? Identify that shape needs encoding and give the two-node counterexample, propose and reject the positional encoding for the right reason, write the preorder codec with reader and writer in matching order and a real cursor, verify the empty and single-node cases, and name the O(height) recursion risk with the iterative fix.
