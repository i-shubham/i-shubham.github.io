Word ladder

Shortest word transformation is BFS — the optimization talk is about neighbor generation and bidirectional search.

60-minute agenda

How I'd open the discussion

I'd start by saying this is shortest-path on an implicit graph where nodes are words and edges connect words that differ by exactly one character. BFS from the start word gives the shortest transformation sequence because all edges have weight 1.

The naive approach generates neighbors by checking every word in the dictionary — O(n × L) per BFS step where n is dictionary size and L is word length. That's too slow when n is large. The optimization is to generate neighbors by trying all 26 replacements at each position — O(26 × L) per word, independent of n. For a 5-letter word that's 130 candidates per step, checked against a hash set in O(1).

For very large dictionaries, I'd mention bidirectional BFS: search from both ends simultaneously and stop when the frontiers meet. This reduces the search space from O(b^d) to O(b^(d/2)) where b is branching factor and d is distance.

Open questions worth asking

  • All words same length?
  • Are start and end words guaranteed to be in the dictionary?
  • Case-sensitive? Lowercase only?
  • Return the length of the path or the actual sequence of words?
  • Can the dictionary have duplicates?
  • What if no transformation sequence exists — return 0 or -1?
  • How large is the dictionary — thousands or millions?
  • Do we need all shortest paths or just one?

Scope I'd lock first

  • In: shortest transformation length using BFS with O(26L) neighbor generation.
  • Out: all shortest paths (Word Ladder II) unless follow-up; A* heuristics.

Functional requirements

  • Input: beginWord, endWord, wordList (list of strings).
  • Output: length of shortest transformation sequence (including start and end).
  • Each step changes exactly one letter. Every intermediate word must be in wordList.

Non-functional / rough numbers

Time

O(n × L × 26) where n = |wordList|, L = word length. Hash set lookup is O(L).

Space

O(n × L) for the word set + BFS queue.

Edge case

endWord not in wordList → return 0 immediately.

Capacity estimate (do this on the board)

n limit

up to 5×10^3 words in LeetCode constraints

L limit

word length up to 10 characters

BFS nodes

worst case visits all n words → 5×10^3 pops

Neighbor gen

26 × L = 260 candidates per word, each checked in O(L) → ~1.3×10^6 hash ops total

Bidirectional

reduces frontier to O(b^(d/2)) — meaningful when d > 6 and b > 10

Approach / design notes

Convert wordList to a set for O(1) lookup. If endWord is not in the set, return 0.

BFS: queue starts with (beginWord, 1). For each word, generate neighbors by replacing each character position with 'a' through 'z'. If the new word is in the word set, add it to the queue and remove it from the set (this acts as 'visited' — no need for a separate visited set). If the new word equals endWord, return current length + 1.

Removing from the set instead of maintaining a separate visited set is a clean trick — it prevents revisiting and saves space.

Bidirectional BFS: maintain two frontiers (sets), one from start and one from end. Each step, expand the smaller frontier. If a generated neighbor is in the other frontier, the paths have met — return the sum of depths. This is significantly faster when the shortest path is long and the branching factor is high.

Deep dive (spend 15–25 minutes here)

beginWord='hit', endWord='cog', wordList=['hot','dot','dog','lot','log','cog'].

word_set = {'hot','dot','dog','lot','log','cog'}. endWord 'cog' is in set.

BFS queue: [('hit', 1)].

Process 'hit' (depth 1): try all positions. pos 0: ait, bit, ..., hot ✓ (in set). Add ('hot', 2). Remove 'hot' from set. pos 1: hat, hbt, ..., none in set besides 'hot' already removed. pos 2: hia, hib, ..., none in set. Queue: [('hot', 2)]. Set: {'dot','dog','lot','log','cog'}.

Process 'hot' (depth 2): pos 0: aot, bot, ..., dot ✓, ..., lot ✓. Add both at depth 3. Remove from set. pos 1: hat, hbt, ..., none new. pos 2: hoa, hob, ..., none. Queue: [('dot',3), ('lot',3)]. Set: {'dog','log','cog'}.

Process 'dot' (depth 3): pos 2: doa..dog ✓. Add ('dog',4). Remove. Process 'lot' (depth 3): pos 2: loa..log ✓. Add ('log',4). Remove. Queue: [('dog',4),('log',4)]. Set: {'cog'}.

Process 'dog' (depth 4): pos 0: aog, bog, cog ✓. cog == endWord → return 4+1 = 5.

Shortest path: hit → hot → dot → dog → cog (5 words, 4 transformations).

from collections import deque
from typing import List


def ladder_length(begin_word: str, end_word: str, word_list: List[str]) -> int:
    """BFS from begin_word — try all single-char mutations at each level.
    Returns the length of the shortest transformation sequence, or 0."""
    word_set = set(word_list)
    if end_word not in word_set:
        return 0

    queue = deque([(begin_word, 1)])
    while queue:
        word, depth = queue.popleft()
        for i in range(len(word)):
            for c in "abcdefghijklmnopqrstuvwxyz":
                candidate = word[:i] + c + word[i + 1:]
                if candidate == end_word:
                    return depth + 1
                if candidate in word_set:
                    word_set.discard(candidate)  # mark visited
                    queue.append((candidate, depth + 1))
    return 0


def ladder_length_bidir(begin_word: str, end_word: str, word_list: List[str]) -> int:
    """Bidirectional BFS: expand from both ends, always pick the smaller frontier.
    Meets in the middle for O(sqrt) speedup on branchy graphs."""
    word_set = set(word_list)
    if end_word not in word_set:
        return 0

    front, back = {begin_word}, {end_word}
    word_set.discard(begin_word)
    depth = 1
    while front:
        # Always expand the smaller frontier for efficiency
        if len(front) > len(back):
            front, back = back, front
        nxt = set()
        for word in front:
            for i in range(len(word)):
                for c in "abcdefghijklmnopqrstuvwxyz":
                    candidate = word[:i] + c + word[i + 1:]
                    if candidate in back:
                        return depth + 1  # frontiers met
                    if candidate in word_set:
                        word_set.discard(candidate)
                        nxt.add(candidate)
        front = nxt
        depth += 1
    return 0
use std::collections::{HashSet, VecDeque};

/// BFS word ladder: try all single-char mutations at each level.
fn ladder_length(begin: &str, end: &str, word_list: &[&str]) -> u32 {
    let mut word_set: HashSet<String> = word_list.iter().map(|s| s.to_string()).collect();
    if !word_set.contains(end) { return 0; }

    let mut queue: VecDeque<(String, u32)> = VecDeque::new();
    queue.push_back((begin.to_string(), 1));
    while let Some((word, depth)) = queue.pop_front() {
        let bytes = word.as_bytes().to_vec();
        for i in 0..bytes.len() {
            for c in b'a'..=b'z' {
                let mut candidate = bytes.clone();
                candidate[i] = c;
                let cand = String::from_utf8(candidate).unwrap();
                if cand == end { return depth + 1; }
                if word_set.remove(&cand) {
                    queue.push_back((cand, depth + 1));
                }
            }
        }
    }
    0
}

/// Bidirectional BFS: expand smaller frontier, meet in the middle.
fn ladder_length_bidir(begin: &str, end: &str, word_list: &[&str]) -> u32 {
    let mut word_set: HashSet<String> = word_list.iter().map(|s| s.to_string()).collect();
    if !word_set.contains(end) { return 0; }

    let mut front: HashSet<String> = [begin.to_string()].into();
    let mut back: HashSet<String> = [end.to_string()].into();
    word_set.remove(begin);
    let mut depth = 1u32;
    while !front.is_empty() {
        // Always expand the smaller frontier
        if front.len() > back.len() { std::mem::swap(&mut front, &mut back); }
        let mut nxt = HashSet::new();
        for word in &front {
            let bytes = word.as_bytes().to_vec();
            for i in 0..bytes.len() {
                for c in b'a'..=b'z' {
                    let mut cand = bytes.clone();
                    cand[i] = c;
                    let s = String::from_utf8(cand).unwrap();
                    if back.contains(&s) { return depth + 1; }
                    if word_set.remove(&s) { nxt.insert(s); }
                }
            }
        }
        front = nxt;
        depth += 1;
    }
    0
}
#import <Foundation/Foundation.h>
#include <string>
#include <unordered_set>
#include <queue>

// BFS word ladder: try all single-char mutations at each level
static int ladderLength(const std::string &begin, const std::string &end,
                        const std::vector<std::string> &wordList) {
    std::unordered_set<std::string> wordSet(wordList.begin(), wordList.end());
    if (!wordSet.count(end)) return 0;

    std::queue<std::pair<std::string, int>> q;
    q.push({begin, 1});
    while (!q.empty()) {
        auto [word, depth] = q.front(); q.pop();
        for (int i = 0; i < (int)word.size(); i++) {
            std::string cand = word;
            for (char c = 'a'; c <= 'z'; c++) {
                cand[i] = c;
                if (cand == end) return depth + 1;
                if (wordSet.erase(cand))       // erase returns 1 if found
                    q.push({cand, depth + 1});
            }
            cand[i] = word[i]; // restore
        }
    }
    return 0;
}

// Bidirectional BFS: expand smaller frontier, meet in the middle
static int ladderLengthBidir(const std::string &begin, const std::string &end,
                             const std::vector<std::string> &wordList) {
    std::unordered_set<std::string> wordSet(wordList.begin(), wordList.end());
    if (!wordSet.count(end)) return 0;

    std::unordered_set<std::string> front = {begin}, back = {end};
    wordSet.erase(begin);
    int depth = 1;
    while (!front.empty()) {
        if (front.size() > back.size()) std::swap(front, back);
        std::unordered_set<std::string> nxt;
        for (auto &word : front) {
            for (int i = 0; i < (int)word.size(); i++) {
                std::string cand = word;
                for (char c = 'a'; c <= 'z'; c++) {
                    cand[i] = c;
                    if (back.count(cand)) return depth + 1; // frontiers met
                    if (wordSet.erase(cand)) nxt.insert(cand);
                }
            }
        }
        front = nxt;
        depth++;
    }
    return 0;
}

Request path / sequence

Trade-offs I'd say out loud

26L vs dictionary scan

26L is better when dictionary is large; dictionary scan wins for very long words with tiny dictionaries.

Set removal vs visited set

Removing from word_set doubles as visited marking — saves space.

Bidirectional BFS

Roughly square-root speedup but more complex code; worth it for long shortest paths.

Where it usually breaks

  • Not checking if endWord is in the dictionary — infinite BFS.
  • Generating the same neighbor twice from different parents (visited check prevents it).
  • String concatenation cost — O(L) per candidate, often overlooked in complexity analysis.
  • Using DFS instead of BFS — finds a path but not the shortest.
  • Not removing used words from set — BFS revisits and TLEs on large inputs.

Follow-ups if time remains

  • Word Ladder II — find all shortest paths; BFS for distances, then DFS backtrack.
  • Wildcard patterns (h_t matches hat, hit, hot) — precompute pattern → word mapping.
  • Minimum genetic mutation — same BFS, alphabet is {A, C, G, T}, length is 8.
  • Open the lock — BFS on 4-digit combinations, each digit ±1 as neighbor generation.
