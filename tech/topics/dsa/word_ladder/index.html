1. Problem statement & explanation

Given beginWord, endWord, and a dictionary wordList, a transformation sequence is a chain beginWord → w₁ → w₂ → … → endWord where each step changes exactly one letter and every word after the first must exist in wordList. Return the number of words in the shortest such sequence, or 0 if none exists.

Two reframings to say out loud immediately. First: this is a graph where each word is a vertex and an edge joins two words that differ in exactly one letter. Shortest path on an unweighted graph is BFS — no Dijkstra, no DP. Second, and more important: you must not build that graph. With 5000 words the pairwise edge check is 12.5 million comparisons, and the graph is only ever traversed once. Instead, generate a word's neighbours on demand by trying every single-letter substitution and testing membership in a hash set.

That is the actual content of the question: recognising that the graph is implicit, and that neighbour generation should scale with the word length and the alphabet rather than with the dictionary size.

1.1 Input / output

Signature

contract
ladder_length(begin_word: str, end_word: str, word_list: List[str]) -> int

# or 0 when no sequence exists.

Worked examples

Example 1 — the standard case 
Input:  beginWord = "hit", endWord = "cog",
        wordList  = ["hot","dot","dog","lot","log","cog"]
Output: 5
Why:    "hit" -> "hot" -> "dot" -> "dog" -> "cog"
        That is 5 WORDS and 4 EDGES. The answer counts words.
Note:   "hit" -> "hot" -> "lot" -> "log" -> "cog" is an equally short
        alternative -- the shortest length is unique, the path is not.
Example 2 — unreachable target 
Input:  beginWord = "hit", endWord = "cog",
        wordList  = ["hot","dot","dog","lot","log"]     # no "cog"
Output: 0
Why:    endWord is not in wordList, so it can never be a legal step.
        Check this FIRST -- it is a one-line early exit.
Example 3 — the ones that catch people 
begin="a", end="c", list=["a","b","c"]        -> 2    ("a" -> "c" directly)
begin="hot", end="dog", list=["hot","dog"]    -> 0    (2 letters differ)
begin="hit", end="hot", list=["hot"]          -> 2    (beginWord need NOT
                                                       be in wordList)
begin="talk", end="tail", list=["talk","tons","fall","tail","gale","hall","negs"]
                                              -> 0    (no single-letter bridge
                                                       from "talk" to "tail")

Constraints to state back

  • 1 ≤ beginWord.length ≤ 10 and endWord.length == beginWord.length; every word in the list has that same length. Call it L ≤ 10.
  • 1 ≤ wordList.length ≤ 5000. Call it N. All words are unique.
  • All words consist of lowercase English letters, so the alphabet is Σ = 26.
  • beginWord != endWord, and beginWord does not have to be in wordList — but endWord must be, or the answer is 0.
  • The return value counts words including both endpoints, so a direct single-letter hop returns 2, not 1.

2. Open questions & clarifications

  • Are all words the same length? Stated here, but confirm. If insertions and deletions were allowed this becomes an edit-distance graph and neighbour generation changes completely.
  • Must beginWord be in the dictionary? No — and that asymmetry with endWord is a deliberate trap. Say both rules back.
  • Number of words or number of steps? Off by one between the two. Read example 1 back: 5 words, 4 transformations.
  • The count, or the actual sequence? Returning one path needs parent pointers; returning all shortest paths is Word Ladder II and is a genuinely harder problem — do not accidentally solve it.
  • What is the alphabet? Lowercase English gives 26 substitutions per position. If it were full Unicode, generating candidates becomes hopeless and the bucket approach in section 5 is the only option.
  • Relative size of N, L and Σ. This decides the algorithm. Neighbour generation costs Σ·L per word; pairwise comparison costs N·L. Generation wins whenever Σ·L < N·L, i.e. whenever the dictionary is larger than the alphabet — almost always.
  • Can the dictionary be mutated? Removing words as they are visited is the cheapest possible visited-set. If the caller needs the list intact, I need a separate set and should say so.
  • Duplicates in the list? Stated unique. A set handles them anyway, but confirm rather than assume.
  • Does the dictionary fit in memory? At 5000 words, trivially. At 10⁷ words, the frontier and the visited set become the design problem and bidirectional search stops being an optimisation and becomes a requirement.
  • Is this called once or many times against the same dictionary? Repeated queries justify precomputing the wildcard bucket index once and amortising it.

2.1 Suggestions to the candidate

  • Do not jump to “BFS” and start typing. Everyone says BFS. What distinguishes answers is the next sentence: “…on an implicit graph, because materialising the edges costs O(N²L) and I only traverse them once.” Say both halves.
  • Justify BFS over DFS explicitly. “The graph is unweighted, so the first time BFS reaches endWord it is via a shortest path. DFS would have to explore exhaustively to prove minimality.” One sentence, and it forecloses a whole line of questioning.
  • Do not skip the baseline. Two minutes on the pairwise-graph version gives you a number to beat and shows the optimisation was derived. Compute both: N²L = 2.5 × 10⁸ versus 26·N·L² = 1.3 × 10⁷.
  • Mark visited at enqueue time, not at dequeue time. If you mark on dequeue, the same word can be enqueued many times from one BFS level and the queue blows up. Removing the word from the dictionary as you enqueue it is the tidiest form of this.
  • Handle the level counter deliberately. Either drain one whole level per iteration and increment a counter, or store (word, distance) pairs. Both are fine; picking one and stating it prevents the classic off-by-one where the answer is 4 instead of 5.
  • Check endWord in wordList first. One line, and it converts a whole class of inputs into an instant correct answer.
  • Restore the mutated character. When you edit a character buffer in place to build candidates, put the original back before moving to the next position. Forgetting this corrupts every subsequent candidate and is a very common silent bug.
  • Offer bidirectional BFS as an optimisation, not the first answer. Get the plain BFS correct and complete first. Then say “the frontier grows exponentially in depth, so searching from both ends turns b^d into 2b^(d/2)” and implement it if there is time.

3. Brute-force approach

Do exactly what the problem describes: build the graph, then search it. Compare every pair of words, add an edge when they differ in exactly one position, then run an ordinary BFS over the adjacency list.

  1. Early exit if endWord is not in the list.
  2. Append beginWord to the vertex set if it is not already there.
  3. For every pair (i, j), test “differ in exactly one position” in O(L) with early termination at the second difference. Add an undirected edge if so.
  4. BFS from beginWord, tracking distance in words. Return the distance when endWord is dequeued, or 0 if the queue drains.
There is a worse brute force — name it and reject it

Backtracking over all transformation sequences and keeping the shortest. The number of paths is exponential in the dictionary size, and it recomputes the same sub-paths endlessly. Name it in one sentence to show you have bounded the search space, then move on — BFS's level order is what makes minimality free.

from collections import deque
from typing import List


def differs_by_one(a: str, b: str) -> bool:
    """True when a and b differ in exactly one position. O(L), early exit."""
    diff = 0
    for ca, cb in zip(a, b):
        if ca != cb:
            diff += 1
            if diff > 1:
                return False
    return diff == 1


def ladder_length_brute(begin_word: str, end_word: str,
                        word_list: List[str]) -> int:
    """Materialise the whole graph by comparing every pair, then BFS it."""
    if end_word not in word_list:
        return 0                           # endWord must be a legal step

    words = list(word_list)
    if begin_word not in words:
        words.append(begin_word)           # beginWord need not be in the list

    n = len(words)
    adj: List[List[int]] = [[] for _ in range(n)]
    for i in range(n):                     # O(N^2) pairs, O(L) each
        for j in range(i + 1, n):
            if differs_by_one(words[i], words[j]):
                adj[i].append(j)
                adj[j].append(i)

    start, target = words.index(begin_word), words.index(end_word)

    dist = [0] * n                         # 0 doubles as "not visited"
    dist[start] = 1                        # the answer counts WORDS
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node == target:
            return dist[node]
        for nxt in adj[node]:
            if dist[nxt] == 0:
                dist[nxt] = dist[node] + 1
                queue.append(nxt)          # mark visited AT ENQUEUE time
    return 0

/// True when a and b differ in exactly one position. O(L), early exit.
fn differs_by_one(a: &str, b: &str) -> bool {
    let mut diff = 0;
    for (ca, cb) in a.bytes().zip(b.bytes()) {
        if ca != cb {
            diff += 1;
            if diff > 1 {
                return false;
            }
        }
    }
    diff == 1
}

/// Materialise the whole graph by comparing every pair, then BFS it.
pub fn ladder_length_brute(
    begin_word: &str,
    end_word: &str,
    word_list: &[String],
) -> usize {
    if !word_list.iter().any(|w| w == end_word) {
        return 0;                          // endWord must be a legal step
    }

    let mut words: Vec<String> = word_list.to_vec();
    if !words.iter().any(|w| w == begin_word) {
        words.push(begin_word.to_string()); // beginWord need not be listed
    }

    let n = words.len();
    let mut adj: Vec<Vec<usize>> = vec![Vec::new(); n];
    for i in 0..n {                        // O(N^2) pairs, O(L) each
        for j in (i + 1)..n {
            if differs_by_one(&words[i], &words[j]) {
                adj[i].push(j);
                adj[j].push(i);
            }
        }
    }

    let start = words.iter().position(|w| w == begin_word).unwrap();
    let target = words.iter().position(|w| w == end_word).unwrap();

    let mut dist = vec![0usize; n];        // 0 doubles as "not visited"
    dist[start] = 1;                       // the answer counts WORDS
    let mut queue: VecDeque<usize> = VecDeque::from([start]);

    while let Some(node) = queue.pop_front() {
        if node == target {
            return dist[node];
        }
        for k in 0..adj[node].len() {
            let nxt = adj[node][k];
            if dist[nxt] == 0 {
                dist[nxt] = dist[node] + 1;
                queue.push_back(nxt);      // mark visited AT ENQUEUE time
            }
        }
    }
    0
}

import java.util.ArrayList;

class Solution {

    /** True when a and b differ in exactly one position. O(L), early exit. */
    private boolean differsByOne(String a, String b) {
        int diff = 0;
        for (int i = 0; i < a.length(); i++) {
            if (a.charAt(i) != b.charAt(i)) {
                if (++diff > 1) return false;
            }
        }
        return diff == 1;
    }

    /** Materialise the whole graph by comparing every pair, then BFS it. */
    public int ladderLengthBrute(String beginWord, String endWord,
                                 List<String> wordList) {
        if (!wordList.contains(endWord)) {
            return 0;                          // endWord must be a legal step
        }

        List<String> words = new ArrayList<>(wordList);
        if (!words.contains(beginWord)) {
            words.add(beginWord);              // beginWord need not be listed
        }

        int n = words.size();
        List<List<Integer>> adj = new ArrayList<>(n);
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int i = 0; i < n; i++) {           // O(N^2) pairs, O(L) each
            for (int j = i + 1; j < n; j++) {
                if (differsByOne(words.get(i), words.get(j))) {
                    adj.get(i).add(j);
                    adj.get(j).add(i);
                }
            }
        }

        int start = words.indexOf(beginWord);
        int target = words.indexOf(endWord);

        int[] dist = new int[n];               // 0 doubles as "not visited"
        dist[start] = 1;                       // the answer counts WORDS
        Deque<Integer> queue = new ArrayDeque<>();
        queue.add(start);

        while (!queue.isEmpty()) {
            int node = queue.poll();
            if (node == target) return dist[node];
            for (int nxt : adj.get(node)) {
                if (dist[nxt] == 0) {
                    dist[nxt] = dist[node] + 1;
                    queue.add(nxt);            // mark visited AT ENQUEUE time
                }
            }
        }
        return 0;
    }
}

// True when a and b differ in exactly one position. O(L), early exit.
static bool differsByOne(const std::string& a, const std::string& b) {
    int diff = 0;
    for (std::size_t i = 0; i < a.size(); ++i) {
        if (a[i] != b[i] && ++diff > 1) return false;
    }
    return diff == 1;
}

// Materialise the whole graph by comparing every pair, then BFS it.
int ladderLengthBrute(const std::string& beginWord,
                      const std::string& endWord,
                      const std::vector<std::string>& wordList) {
    if (std::find(wordList.begin(), wordList.end(), endWord) == wordList.end()) {
        return 0;                              // endWord must be a legal step
    }

    std::vector<std::string> words = wordList;
    if (std::find(words.begin(), words.end(), beginWord) == words.end()) {
        words.push_back(beginWord);            // beginWord need not be listed
    }

    const int n = static_cast<int>(words.size());
    std::vector<std::vector<int>> adj(n);
    for (int i = 0; i < n; ++i) {              // O(N^2) pairs, O(L) each
        for (int j = i + 1; j < n; ++j) {
            if (differsByOne(words[i], words[j])) {
                adj[i].push_back(j);
                adj[j].push_back(i);
            }
        }
    }

    const int start = static_cast<int>(
        std::find(words.begin(), words.end(), beginWord) - words.begin());
    const int target = static_cast<int>(
        std::find(words.begin(), words.end(), endWord) - words.begin());

    std::vector<int> dist(n, 0);               // 0 doubles as "not visited"
    dist[start] = 1;                           // the answer counts WORDS
    std::queue<int> q;
    q.push(start);

    while (!q.empty()) {
        const int node = q.front();
        q.pop();
        if (node == target) return dist[node];
        for (int nxt : adj[node]) {
            if (dist[nxt] == 0) {
                dist[nxt] = dist[node] + 1;
                q.push(nxt);                   // mark visited AT ENQUEUE time
            }
        }
    }
    return 0;
}

3.2 Complexity

Time O(N²·L)

The build step dominates: N(N−1)/2 pairs at O(L) each. At N = 5000, L = 10 that is ~1.25 × 10⁸ character comparisons. The BFS itself is only O(V + E).

Space O(N²) worst case

The adjacency list holds one entry per edge. Dense dictionaries (many words differing by one letter) approach N² edges — and we store all of them to walk each exactly once.

Why this is not the final answer

To find the neighbours of one word we compared it against the entire dictionary. But a word of length L over an alphabet of size 26 has only 25·L possible single-letter variants — at most 250 here. So instead of asking “which of these 5000 words is adjacent to me?”, enumerate the 250 variants and ask the hash set which of them exist. The cost of neighbour generation becomes independent of dictionary size.

4. Optimised approach

Key insight: the graph is implicit. Put the dictionary in a hash set and never build an edge list. For the word at the BFS frontier, generate every single-letter variant and keep the ones the set contains. BFS level order guarantees the first time endWord appears, it appears at minimum depth.

  1. Put wordList into a hash set. If endWord is absent, return 0 immediately.
  2. Remove beginWord from the set and seed the frontier with it. Distance starts at 1, because the answer counts words.
  3. Drain the frontier one level at a time. For each word: if it equals endWord, return the current distance.
  4. Otherwise, for each position i and each letter c ≠ word[i], form the candidate. If the set contains it, remove it from the set (that is the visited mark) and add it to the next level.
  5. After the level is drained, increment the distance. If the frontier empties, return 0.
The invariant to say out loud

Every word in the frontier is at the same BFS distance from beginWord, and that distance is minimal — because a word is removed from the dictionary the instant it is first enqueued, so it can never be reached again by a longer route. Deleting from the dictionary is the visited set: no second structure, and no possibility of a word entering the queue twice.

4.1 Code — Python, Rust, Java, C++

from collections import deque
from string import ascii_lowercase
from typing import List


def ladder_length(begin_word: str, end_word: str,
                  word_list: List[str]) -> int:
    """BFS on the IMPLICIT graph: neighbours are generated, never stored.

    Invariant: every word in `frontier` sits at BFS distance `steps` from
    begin_word, and that distance is minimal.
    """
    dictionary = set(word_list)
    if end_word not in dictionary:
        return 0                           # endWord can never be a legal step

    dictionary.discard(begin_word)         # begin_word may or may not be listed
    frontier = deque([begin_word])
    steps = 1                              # the answer counts WORDS

    while frontier:
        for _ in range(len(frontier)):     # drain exactly one BFS level
            word = frontier.popleft()
            if word == end_word:
                return steps

            for i in range(len(word)):
                prefix, suffix = word[:i], word[i + 1:]
                for c in ascii_lowercase:
                    if c == word[i]:
                        continue           # not a transformation
                    candidate = prefix + c + suffix
                    if candidate in dictionary:
                        # Removing IS the visited mark: a word can never be
                        # enqueued twice, so the queue stays O(N).
                        dictionary.remove(candidate)
                        frontier.append(candidate)
        steps += 1

    return 0                               # end_word unreachable
use std::collections::{HashSet, VecDeque};

/// BFS on the IMPLICIT graph: neighbours are generated, never stored.
///
/// Invariant: every word in `frontier` sits at BFS distance `steps` from
/// `begin_word`, and that distance is minimal.
pub fn ladder_length(
    begin_word: &str,
    end_word: &str,
    word_list: Vec<String>,
) -> usize {
    let mut dict: HashSet<String> = word_list.into_iter().collect();
    if !dict.contains(end_word) {
        return 0;                          // endWord can never be a legal step
    }

    dict.remove(begin_word);               // may or may not have been present
    let mut frontier: VecDeque<String> = VecDeque::new();
    frontier.push_back(begin_word.to_string());
    let mut steps = 1usize;                // the answer counts WORDS

    while !frontier.is_empty() {
        for _ in 0..frontier.len() {       // drain exactly one BFS level
            let word = frontier.pop_front().unwrap();
            if word == end_word {
                return steps;
            }

            let mut bytes = word.into_bytes();
            for i in 0..bytes.len() {
                let original = bytes[i];
                for c in b'a'..=b'z' {
                    if c == original {
                        continue;          // not a transformation
                    }
                    bytes[i] = c;
                    // Borrow the buffer to probe; only allocate on a hit.
                    let candidate = std::str::from_utf8(&bytes).unwrap();
                    if dict.remove(candidate) {
                        // remove() returning true IS the visited mark.
                        frontier.push_back(candidate.to_string());
                    }
                }
                bytes[i] = original;       // restore before the next position
            }
        }
        steps += 1;
    }

    0                                      // end_word unreachable
}
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {

    /**
     * BFS on the IMPLICIT graph: neighbours are generated, never stored.
     *
     * Invariant: every word in the queue sits at BFS distance `steps` from
     * beginWord, and that distance is minimal.
     */
    public int ladderLength(String beginWord, String endWord,
                            List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        if (!dict.contains(endWord)) {
            return 0;                      // endWord can never be a legal step
        }

        dict.remove(beginWord);            // may or may not have been present
        Deque<String> frontier = new ArrayDeque<>();
        frontier.add(beginWord);
        int steps = 1;                     // the answer counts WORDS

        while (!frontier.isEmpty()) {
            for (int size = frontier.size(); size > 0; size--) {  // one level
                String word = frontier.poll();
                if (word.equals(endWord)) {
                    return steps;
                }

                char[] chars = word.toCharArray();
                for (int i = 0; i < chars.length; i++) {
                    char original = chars[i];
                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == original) continue;   // not a transformation
                        chars[i] = c;
                        String candidate = new String(chars);
                        // remove() returning true IS the visited mark.
                        if (dict.remove(candidate)) {
                            frontier.add(candidate);
                        }
                    }
                    chars[i] = original;   // restore before the next position
                }
            }
            steps++;
        }

        return 0;                          // endWord unreachable
    }
}

// BFS on the IMPLICIT graph: neighbours are generated, never stored.
//
// Invariant: every word in the queue sits at BFS distance `steps` from
// beginWord, and that distance is minimal.
int ladderLength(const std::string& beginWord,
                 const std::string& endWord,
                 const std::vector<std::string>& wordList) {
    std::unordered_set<std::string> dict(wordList.begin(), wordList.end());
    if (dict.find(endWord) == dict.end()) {
        return 0;                          // endWord can never be a legal step
    }

    dict.erase(beginWord);                 // may or may not have been present
    std::queue<std::string> frontier;
    frontier.push(beginWord);
    int steps = 1;                         // the answer counts WORDS

    while (!frontier.empty()) {
        for (std::size_t size = frontier.size(); size > 0; --size) {  // level
            std::string word = frontier.front();
            frontier.pop();
            if (word == endWord) {
                return steps;
            }

            for (std::size_t i = 0; i < word.size(); ++i) {
                const char original = word[i];
                for (char c = 'a'; c <= 'z'; ++c) {
                    if (c == original) continue;   // not a transformation
                    word[i] = c;
                    // erase() returning 1 IS the visited mark.
                    if (dict.erase(word) > 0) {
                        frontier.push(word);
                    }
                }
                word[i] = original;        // restore before the next position
            }
        }
        ++steps;
    }

    return 0;                              // endWord unreachable
}

4.2 Complexity

Time O(N · L² · Σ)

Each of the N words is expanded at most once; expansion generates L·Σ candidates, each costing O(L) to build and hash. At N = 5000, L = 10, Σ = 26 that is ~1.3 × 10⁷ character operations — about 20× less work than the O(N²L) baseline.

Space O(N · L)

The dictionary set plus the frontier, which holds at most one BFS level. No adjacency list at all — the O(N²) edge storage is gone entirely.

Edge cases this version already handles

endWord missing → instant 0. beginWord not in the list → the discard is a no-op and BFS still starts from it. A direct hop ("a" → "c") → returns 2. Disconnected dictionary → frontier empties, returns 0. Single-character words → L = 1, still correct.

4.3 Variant: bidirectional BFS

A BFS frontier grows roughly as b^d, where b is the branching factor and d the depth. Search from both ends simultaneously and each side only has to reach depth d/2, so the explored set shrinks from b^d to 2·b^(d/2) — for b = 10 and d = 6 that is 200 nodes instead of a million.

  1. Maintain two frontiers: front from beginWord, back from endWord. Use sets, not queues — membership testing is the meeting check.
  2. Each round, swap so you always expand the smaller frontier. This single line is where nearly all of the saving comes from; without it the larger side dominates and you gain almost nothing.
  3. Expand every word in the smaller frontier. If a candidate is in the other frontier, the searches have met — return steps + 1.
  4. Otherwise collect unvisited dictionary candidates into the next frontier. Stop when either side runs dry (no path exists).
The two things that go wrong here

1. The meeting count. Getting steps + 1 versus steps right is the whole answer; derive it on the example rather than guessing. 2. A shared visited set. If both directions write into one visited set you can block the other side from reaching a legitimate meeting point — safe here because we return the moment the frontiers touch, but say why it is safe rather than leaving it implicit.

def ladder_length_bidirectional(begin_word: str, end_word: str,
                                word_list: List[str]) -> int:
    """Search from both ends; stop when the frontiers touch."""
    dictionary = set(word_list)
    if end_word not in dictionary:
        return 0

    front = {begin_word}
    back = {end_word}
    visited = {begin_word, end_word}
    steps = 1

    while front and back:
        # Always expand the SMALLER frontier. This one line is where
        # essentially all of the speedup comes from.
        if len(front) > len(back):
            front, back = back, front

        nxt: set = set()
        for word in front:
            for i in range(len(word)):
                prefix, suffix = word[:i], word[i + 1:]
                for c in ascii_lowercase:
                    candidate = prefix + c + suffix
                    if candidate in back:
                        # The two searches met: one more word joins them.
                        return steps + 1
                    if candidate in dictionary and candidate not in visited:
                        visited.add(candidate)
                        nxt.add(candidate)
        front = nxt
        steps += 1

    return 0
use std::collections::HashSet;
use std::mem;

/// Search from both ends; stop when the frontiers touch.
pub fn ladder_length_bidirectional(
    begin_word: &str,
    end_word: &str,
    word_list: Vec<String>,
) -> usize {
    let dict: HashSet<String> = word_list.into_iter().collect();
    if !dict.contains(end_word) {
        return 0;
    }

    let mut front: HashSet<String> = HashSet::from([begin_word.to_string()]);
    let mut back: HashSet<String> = HashSet::from([end_word.to_string()]);
    let mut visited: HashSet<String> =
        HashSet::from([begin_word.to_string(), end_word.to_string()]);
    let mut steps = 1usize;

    while !front.is_empty() && !back.is_empty() {
        // Always expand the SMALLER frontier -- this is the whole speedup.
        if front.len() > back.len() {
            mem::swap(&mut front, &mut back);
        }

        let mut next: HashSet<String> = HashSet::new();
        for word in &front {
            let mut bytes = word.clone().into_bytes();
            for i in 0..bytes.len() {
                let original = bytes[i];
                for c in b'a'..=b'z' {
                    bytes[i] = c;
                    let candidate = std::str::from_utf8(&bytes).unwrap();
                    if back.contains(candidate) {
                        // The searches met: one more word joins them.
                        return steps + 1;
                    }
                    if dict.contains(candidate) && !visited.contains(candidate) {
                        visited.insert(candidate.to_string());
                        next.insert(candidate.to_string());
                    }
                }
                bytes[i] = original;
            }
        }
        front = next;
        steps += 1;
    }

    0
}

class Solution {

    /** Search from both ends; stop when the frontiers touch. */
    public int ladderLengthBidirectional(String beginWord, String endWord,
                                         List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        if (!dict.contains(endWord)) {
            return 0;
        }

        Set<String> front = new HashSet<>();
        Set<String> back = new HashSet<>();
        front.add(beginWord);
        back.add(endWord);

        Set<String> visited = new HashSet<>();
        visited.add(beginWord);
        visited.add(endWord);
        int steps = 1;

        while (!front.isEmpty() && !back.isEmpty()) {
            // Always expand the SMALLER frontier -- the whole speedup.
            if (front.size() > back.size()) {
                Set<String> swap = front;
                front = back;
                back = swap;
            }

            Set<String> next = new HashSet<>();
            for (String word : front) {
                char[] chars = word.toCharArray();
                for (int i = 0; i < chars.length; i++) {
                    char original = chars[i];
                    for (char c = 'a'; c <= 'z'; c++) {
                        chars[i] = c;
                        String candidate = new String(chars);
                        if (back.contains(candidate)) {
                            // The searches met: one more word joins them.
                            return steps + 1;
                        }
                        // add() returns false when already visited.
                        if (dict.contains(candidate) && visited.add(candidate)) {
                            next.add(candidate);
                        }
                    }
                    chars[i] = original;
                }
            }
            front = next;
            steps++;
        }

        return 0;
    }
}

// Search from both ends; stop when the frontiers touch.
int ladderLengthBidirectional(const std::string& beginWord,
                              const std::string& endWord,
                              const std::vector<std::string>& wordList) {
    std::unordered_set<std::string> dict(wordList.begin(), wordList.end());
    if (dict.find(endWord) == dict.end()) {
        return 0;
    }

    std::unordered_set<std::string> front{beginWord};
    std::unordered_set<std::string> back{endWord};
    std::unordered_set<std::string> visited{beginWord, endWord};
    int steps = 1;

    while (!front.empty() && !back.empty()) {
        // Always expand the SMALLER frontier -- the whole speedup.
        if (front.size() > back.size()) {
            front.swap(back);
        }

        std::unordered_set<std::string> next;
        for (const std::string& source : front) {
            std::string word = source;
            for (std::size_t i = 0; i < word.size(); ++i) {
                const char original = word[i];
                for (char c = 'a'; c <= 'z'; ++c) {
                    word[i] = c;
                    if (back.count(word) > 0) {
                        // The searches met: one more word joins them.
                        return steps + 1;
                    }
                    // insert().second is false when already visited.
                    if (dict.count(word) > 0 && visited.insert(word).second) {
                        next.insert(word);
                    }
                }
                word[i] = original;
            }
        }
        front = std::move(next);
        ++steps;
    }

    return 0;
}
Time O(N · L² · Σ) worst case

Asymptotically identical — in the worst case both searches still cover the whole dictionary. In practice the explored node count drops from b^d to 2b^(d/2), routinely a 10–100× win on deep ladders.

Space O(N · L)

Two frontiers plus a visited set. Same order as before, and each individual frontier is much smaller, which matters when the frontier is what does not fit in memory.

Which one would I ship?

Plain BFS for a 5000-word dictionary — it is already 13 million operations and simpler to get right under time pressure. Bidirectional the moment the dictionary is large or the ladder is long, because the frontier, not the total work, is the binding constraint. Write the single-directional version first, then offer this as the optimisation with the b^(d/2) justification.

5. Follow-up discussion if time permits

  • Word Ladder II — return all shortest sequences. BFS to compute the distance layers, recording every predecessor that sits one layer back, then DFS backwards from endWord to enumerate paths. Critically: do not backtrack during the BFS, and do not prune a node just because it was visited — multiple parents at the same depth are exactly what you need. The output itself can be exponential, so the complexity is output-sensitive.
  • Wildcard bucket index instead of 26-letter generation. Precompute a map from patterns like "h*t" to the words matching them. That costs O(N·L²) once and removes the Σ factor from every expansion — a clear win when the alphabet is large, or when many queries hit the same dictionary. Worth naming as “an index, amortised across queries”.
  • Very large dictionary (10⁷+ words). The 26·L generation stays constant per word, which is the point — the pairwise approach would be 10¹⁴ comparisons. Combine bidirectional search with a memory-mapped or sharded dictionary, and note that the frontier becomes the memory bottleneck.
  • Weighted transformations. If changing a vowel is cheaper than a consonant, BFS is no longer valid and it becomes Dijkstra: O(E log V). The right answer is not “use Dijkstra” but “BFS is only correct because all edges cost 1.”
  • A* with a heuristic. Hamming distance to endWord is admissible (each step fixes at most one position), so A* provably finds the shortest path while expanding fewer nodes. Good answer to “can you beat BFS?” — and note it composes badly with bidirectional search, which is why most implementations pick one.
  • Insertions and deletions allowed, not just substitutions. Now words of different lengths are neighbours and it becomes an edit-distance-1 graph. Neighbour generation grows to O(L·Σ) substitutions + O(L·Σ) insertions + O(L) deletions, and a trie or BK-tree becomes the better index.
  • Connected components of the whole dictionary. Union-find over the wildcard buckets answers “is any ladder possible between these two words?” in near-constant time after O(N·L) preprocessing — without finding the path. Nice demonstration of matching the structure to the actual question.
  • Parallelising the BFS. Level-synchronous BFS parallelises cleanly: partition the frontier across workers, have each generate candidates locally, then deduplicate at the level boundary. The dedup is the interesting part, and it is the same design as distributed graph frameworks.
  • What does “good enough” look like here? Recognise unweighted shortest path → BFS, and say the graph must stay implicit. Get the early exit on endWord, the visited-at-enqueue rule, and the words-not-edges count all correct. Trace "hit" → "cog". Then offer bidirectional BFS with the b^(d/2) reasoning and the always-expand-the-smaller-side detail.
