Remove invalid parentheses

Not “is it valid?” and not “delete until it works.” Return every distinct string you can get by deleting as few parentheses as possible.

1. Problem statement & explanation

Given a string s of lowercase letters and the two characters '(' and ')', delete the fewest parentheses you can so that what remains is a valid parentheses string. Return all distinct results. Order does not matter.

A string is valid when two things hold at once. Reading left to right, a running balance (plus one for '(', minus one for ')', letters ignored) never goes negative. At the end, that balance is exactly zero. Letters are payload: they never affect the balance, and because deleting a letter cannot fix an imbalance, a minimum-deletion answer always keeps every letter.

Minimum is essential. For "()())()" the empty string is valid, as is "()", but both delete more than necessary. The only length-preserving-enough answers are "(())()" and "()()()" — each deletes a single extra ')'. The problem is therefore a shortest-edit search whose alphabet of edits is “delete this parenthesis.”

1.1 Input / output

Signature

contract
remove_invalid_parentheses(s: str) -> list[str]   # unique valid strings, any order

Worked examples

Example 1 — two ways to drop one extra ')' 
Input:  s = "()())()"
Output: ["(())()", "()()()"]
Why:    balance goes negative at the third ')'. Deleting the ')' at
        index 1 yields "(())()"; deleting the one at index 3 (or 4)
        yields "()()()". Deleting any other single paren leaves it invalid.
Example 2 — letters are cargo, they stay 
Input:  s = "(a)())()"
Output: ["(a())()", "(a)()()"]
Why:    same shape as example 1 with an 'a' glued inside the first pair.
        'a' is never a candidate for deletion.
Example 3 — nothing salvageable 
Input:  s = ")("
Output: [""]
Why:    the prefix ')' is already illegal, and the leftover '(' is an
        unmatched opener. Both must go. The empty string is valid:
        balance never moves and ends at 0.
Example 4 — already valid 
Input:  s = "(a)()"
Output: ["(a)()"]
Why:    zero deletions. Returning a proper subset like "()" would be
        valid but not minimum. The already-valid input is the unique answer.
Example 5 — only letters, or only junk 
Input:  s = "abc"   ->  ["abc"]     (no parentheses: vacuously valid)
Input:  s = "(("    ->  [""]        (two unmatched openers)
Input:  s = "(()"   ->  ["()"]      (drop either '(' ; both yield the same string)
Input:  s = ")(f"   ->  ["f"]       (drop both parens, keep the letter)

Constraints to state back

  • 1 ≤ s.length ≤ 25 — tiny as strings go, which is why exponential search is on the table.
  • s is lowercase English letters plus '(' and ')' only. No other brackets, no whitespace.
  • At most 20 parentheses. That is the real branching limit: 220 ≈ 106 subsets of parens, not 225.
  • Return unique strings, any order. Duplicate generation is a correctness bug even if the judge later uniques them.
  • The empty string is a legal answer (example 3). Do not special-case it away.

2. Open questions & clarifications

  • May letters be deleted? The title says parentheses, and a minimum answer never needs to drop a letter. Confirm: “I will only ever delete '(' or ')'.”
  • What does valid mean once letters are in the mix? Restate the balance rule with letters ignored. "(a)" is valid; "a)(" is not; "abc" is.
  • All minimum strings, or any one? The prompt asks for the full unique list. A greedy stack that deletes the first extra ')' it sees returns one valid string, not all of them, and is the wrong algorithm.
  • Is the empty string allowed? Yes. ")(" must return [""], not an empty list.
  • Does order of the output list matter? No. Dedup does.
  • Are there other bracket types? Not in this prompt. If '[' / '{' appear later, a single integer balance is no longer enough.
  • Can I mutate s in place? You will generate many candidates; treat s as immutable and allocate new strings.
  • Expected n? 25 with 20 parens is the whole story. If n were 104, returning all strings would be the wrong problem.

2.1 Suggestions to the candidate

  • Do not jump to a stack. A stack (or a balance counter) decides whether a string is valid. It does not enumerate every way to make it valid. Validity is a primitive you will call; it is not the solution.
  • Do not present the BFS first. Start from “every subset of parentheses can be kept or dropped.” Once that is on the board, BFS is the observation that strings with k deletions are exactly the neighbours of strings with k−1 deletions, so the first valid layer is optimal.
  • Write is_valid as its own function and test it out loud on "()", ")(", "(a)", "abc". If that helper is wrong, every search built on it is theatre.
  • State the search graph. Vertices are strings. An edge is “delete one parenthesis.” You want every vertex at minimum distance from s that is valid. That sentence is the BFS.
  • Dedup as you generate, not afterwards. Deleting index 3 then 5 is the same string as deleting 5 then 3. A seen set on the generated string is the cheapest correctness fix in the problem.
  • Stop expanding once a valid string appears at the current distance. Further deletions cannot be minimum. Forgetting this still returns correct strings if you filter by length later, but it wastes the entire next 2n layer.
  • Do not delete letters in the neighbour loop. It is wasted branching and, worse, it can look like you did not understand the objective.
  • Trace "()())()" after you code. Show the first layer is the original (invalid), the second layer contains both answers, and you halt. Finding that yourself is the signal; having the interviewer find a missing string is not.

3. Brute-force approach

There are at most 20 parentheses. Each may be kept or deleted, independently. Letters are always kept. That is at most 220 candidate strings. For each candidate, run the O(n) balance check; among the valid ones, keep those with the fewest deletions.

  1. Collect the indices of every '(' and ')'.
  2. Iterate mask from 0 to 2p − 1, where bit b means “delete the parenthesis at idxs[b].”
  3. If this mask deletes more than the best already found, skip it.
  4. Build the candidate, test validity, and replace or extend the answer set when the deletion count is better or equal.
Say this while writing it

Bitmasking the whole string (including letters) is 225 ≈ 33 million and still technically in, but it is the wrong search space: half of those masks delete a letter and cannot be minimum. Restricting the bits to parentheses is the first real optimisation, and it is still brute force.

from typing import List


def is_valid(s: str) -> bool:
    """Balance never negative, ends at zero. Letters are ignored."""
    bal = 0
    for ch in s:
        if ch == '(':
            bal += 1
        elif ch == ')':
            bal -= 1
            if bal < 0:

def remove_invalid_brute(s: str) -> List[str]:
    """Every subset of parentheses deleted; keep the valid, fewest-deleted ones."""
    idxs = [i for i, ch in enumerate(s) if ch in '()']
    p = len(idxs)
    best = p + 1
    found = set()

    for mask in range(1 << p):
        deleted = bin(mask).count('1')
        if deleted > best:                 # already have a cheaper valid string
            continue

        drop = {idxs[b] for b in range(p) if mask & (1 << b)}
        cand = ''.join(ch for i, ch in enumerate(s) if i not in drop)

        if not is_valid(cand):
            continue
        if deleted < best:
            best = deleted
            found = {cand}                 # cheaper: throw away the previous layer
        else:
            found.add(cand)

    return list(found)
use std::collections::HashSet;

fn is_valid(s: &str) -> bool {
    let mut bal: i32 = 0;
    for ch in s.chars() {
        match ch {
            '(' => bal += 1,
            ')' => {
                bal -= 1;
                if bal < 0 {
                    return false;
                }
            }
            _ => {}
        }
    }
    bal == 0
}

/// Every subset of parentheses deleted; keep the valid, fewest-deleted ones.
pub fn remove_invalid_brute(s: &str) -> Vec<String> {
    let chars: Vec<char> = s.chars().collect();
    let idxs: Vec<usize> = chars
        .iter()
        .enumerate()
        .filter(|(_, ch)| **ch == '(' || **ch == ')')
        .map(|(i, _)| i)
        .collect();
    let p = idxs.len();
    let mut best = p + 1;
    let mut found: HashSet<String> = HashSet::new();

    for mask in 0..(1usize << p) {
        let deleted = mask.count_ones() as usize;
        if deleted > best {
            continue;
        }
        let cand: String = chars
            .iter()
            .enumerate()
            .filter(|(i, _)| (0..p).all(|b| mask & (1 << b) == 0 || idxs[b] != *i))
            .map(|(_, ch)| *ch)
            .collect();
        if !is_valid(&cand) {
            continue;
        }
        if deleted < best {
            best = deleted;
            found.clear();
        }
        found.insert(cand);
    }
    found.into_iter().collect()
}
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {

    private boolean isValid(String s) {
        int bal = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                bal++;
            } else if (c == ')') {
                if (--bal < 0) {
                    return false;
                }
            }
        }
        return bal == 0;
    }

    /** Every subset of parentheses deleted; keep the valid, fewest-deleted ones. */
    public List<String> removeInvalidParenthesesBrute(String s) {
        List<Integer> idxs = new ArrayList<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(' || c == ')') {
                idxs.add(i);
            }
        }
        int p = idxs.size();
        int best = p + 1;
        Set<String> found = new HashSet<>();

        for (int mask = 0; mask < (1 << p); mask++) {
            int deleted = Integer.bitCount(mask);
            if (deleted > best) {
                continue;
            }
            StringBuilder cand = new StringBuilder();
            for (int i = 0, b = 0; i < s.length(); i++) {
                if (b < p && idxs.get(b) == i) {
                    boolean drop = (mask & (1 << b)) != 0;
                    b++;
                    if (drop) {
                        continue;
                    }
                }
                cand.append(s.charAt(i));
            }
            String str = cand.toString();
            if (!isValid(str)) {
                continue;
            }
            if (deleted < best) {
                best = deleted;
                found.clear();
            }
            found.add(str);
        }
        return new ArrayList<>(found);
    }
}

// Every subset of parentheses deleted; keep the valid, fewest-deleted ones.
std::vector<std::string> removeInvalidParenthesesBrute(const std::string& s) {
    std::vector<int> idxs;
    for (int i = 0; i < static_cast<int>(s.size()); ++i) {
        if (s[i] == '(' || s[i] == ')') {
            idxs.push_back(i);
        }
    }
    const int p = static_cast<int>(idxs.size());
    int best = p + 1;
    std::unordered_set<std::string> found;

    for (int mask = 0; mask < (1 << p); ++mask) {
        const int deleted = std::popcount(static_cast<unsigned>(mask));
        if (deleted > best) {
            continue;
        }
        std::string cand;
        cand.reserve(s.size());
        for (int i = 0, b = 0; i < static_cast<int>(s.size()); ++i) {
            if (b < p && idxs[b] == i) {
                const bool drop = (mask & (1 << b)) != 0;
                ++b;
                if (drop) {
                    continue;
                }
            }
            cand.push_back(s[i]);
        }
        if (!isValid(cand)) {
            continue;
        }
        if (deleted < best) {
            best = deleted;
            found.clear();
        }
        found.insert(std::move(cand));
    }
    return {found.begin(), found.end()};
}

3.2 Complexity

Time O(n · 2p)

p ≤ 20 parenthesis positions, n ≤ 25. Each mask builds and checks a string in O(n). About 25 million character operations in the worst case — acceptable under these limits, pointless if n grew.

Space O(n · k)

k is the number of distinct minimum answers (plus O(n) to build the current candidate). The search itself is O(1) extra besides the output set.

Why this is not the final answer

Almost every mask deletes too many parentheses. You already know a cheaper valid string exists, yet you still generate the rest. Searching in increasing deletion count — BFS on “delete one more parenthesis” — stops at the first valid layer and never builds those masks.

4. Optimised approach

Key insight: treat strings as vertices of an unweighted graph. From a string, the neighbours are every string obtained by deleting exactly one parenthesis. Distance from s is the number of deletions. Unweighted shortest paths are BFS, so the first layer that contains a valid string is exactly the set of minimum-deletion answers.

  1. Queue the original string. Mark it seen.
  2. While the queue is not empty, process one whole layer (every string of the current deletion count).
  3. If a string in this layer is valid, collect it. Do not generate its children — they have more deletions.
  4. If this layer produced any valid string, stop after draining the layer. Remaining queued children belong to a strictly worse distance.
  5. Otherwise, for each string, delete each parenthesis once, skip letters, skip already-seen results, enqueue the rest.
The invariants to say out loud

(a) Every string in the queue at the start of a layer has the same number of deletions. (b) seen contains every string that has ever been enqueued, so each distinct string is expanded at most once and at its shortest distance. (c) Letters are never deleted, so every generated string still contains every original letter in order. (d) The first layer with a valid string is complete: BFS would have found a cheaper valid string earlier if one existed.

The two bugs this BFS is famous for

Not processing by layer. If you expand neighbours of an invalid string and then later discover a valid string at the same distance, those neighbours are already in the queue at distance + 1. Use a for _ in range(len(queue)) loop (or stop enqueueing once found is true and leave the outer loop when the layer ends).

No seen set. Deleting index i then j produces the same string as j then i. Without seen, the queue explodes even at n = 12. Hash the string, not the deletion sequence.

from collections import deque
from typing import List


def is_valid(s: str) -> bool:
    bal = 0
    for ch in s:
        if ch == '(':
            bal += 1
        elif ch == ')':
            bal -= 1
            if bal < 0:
                return False
    return bal == 0


def remove_invalid_parentheses(s: str) -> List[str]:
    """BFS by deletion count. The first valid layer is the answer.

    Graph: edge = delete one parenthesis. Distance = deletions.
    """
    queue = deque([s])
    seen = {s}
    answers: List[str] = []

    while queue:
        found = False
        for _ in range(len(queue)):        # one distance class
            cur = queue.popleft()
            if is_valid(cur):
                answers.append(cur)
                found = True
                continue                   # valid: children are NOT minimum
            if found:
                continue                   # drain the rest of this layer only
            for i, ch in enumerate(cur):
                if ch not in '()':
                    continue               # letters are never deleted
                nxt = cur[:i] + cur[i + 1:]
                if nxt not in seen:
                    seen.add(nxt)
                    queue.append(nxt)
        if found:
            break                          # next layer would delete more

    return answers

/// BFS by deletion count. The first valid layer is the answer.
pub fn remove_invalid_parentheses(s: &str) -> Vec<String> {
    let mut queue = VecDeque::from([s.to_string()]);
    let mut seen = HashSet::from([s.to_string()]);
    let mut answers = Vec::new();

    while !queue.is_empty() {
        let mut found = false;
        for _ in 0..queue.len() {          // one distance class
            let cur = queue.pop_front().unwrap();
            if is_valid(&cur) {
                answers.push(cur);
                found = true;
                continue;                  // valid: children are NOT minimum
            }
            if found {
                continue;                  // drain the rest of this layer only
            }
            for (i, ch) in cur.char_indices() {
                if ch != '(' && ch != ')' {
                    continue;              // letters are never deleted
                }
                let mut nxt = String::with_capacity(cur.len() - 1);
                nxt.push_str(&cur[..i]);
                nxt.push_str(&cur[i + ch.len_utf8()..]);
                if seen.insert(nxt.clone()) {
                    queue.push_back(nxt);
                }
            }
        }
        if found {
            break;                         // next layer would delete more
        }
    }
    answers
}

     * Graph: edge = delete one parenthesis. Distance = deletions.

    public List<String> removeInvalidParentheses(String s) {

        Set<String> seen = new HashSet<>();

        seen.add(s);

                        queue.add(nxt);
                    }
                }
            }

4.2 Complexity

Time O(n · 2p)

Same worst-case family as brute force: each distinct subsequence of the parentheses can appear as a vertex, and building a neighbour is O(n). In practice it is far smaller because the search stops at distance k (the minimum deletions) instead of walking all 2p masks. Consecutive identical parens also collapse in the seen set.

Space O(n · 2p)

The seen set and queue can hold every distinct neighbour of the current layer. Under the given limits that is still around a million short strings; it is the price of BFS.

Edge cases this version already handles

Already valid → layer 0 succeeds, returns [s]. ")(" → layer 0 and 1 fail, layer 2 yields "". Letters-only → valid immediately. Consecutive extra ')'s produce the same neighbour and are collapsed by seen. The empty result is a one-element list, not an empty list.

4.3 Variant: DFS with a precomputed removal budget

BFS spends memory on a whole layer of strings. You can compute the exact number of '(' and ')' that must be deleted with one linear scan, then DFS with those two budgets. The scan: every unmatched ')' increments right_rem; leftover unmatched '(' at the end is left_rem. Any valid minimum string deletes exactly those counts, nothing else.

The DFS then has four numbers at each index: remaining left-deletes, remaining right-deletes, current balance, and the path. You may delete a '(' only if left_rem > 0, delete a ')' only if right_rem > 0, and keep a ')' only if balance > 0. Letters are always kept. A result set still uniques paths that deleted different indices of the same character run.

from typing import List, Set


def min_removals(s: str) -> tuple[int, int]:
    """How many '(' and ')' *must* be deleted. One left-to-right scan."""
    left = right = 0
    for ch in s:
        if ch == '(':
            left += 1
        elif ch == ')':
            if left:
                left -= 1                  # this ')' closes a live '('
            else:
                right += 1                 # unmatched closer: must delete
    return left, right                     # leftover left = unmatched openers


def remove_invalid_dfs(s: str) -> List[str]:
    """Backtrack with an exact deletion budget. Balance never goes negative."""
    left_rem, right_rem = min_removals(s)
    found: Set[str] = set()

    def dfs(i: int, left: int, right: int, bal: int, path: list) -> None:
        if left < 0 or right < 0 or bal < 0:
            return
        if i == len(s):
            if left == 0 and right == 0 and bal == 0:
                found.add(''.join(path))
            return

        ch = s[i]
        if ch == '(' or ch == ')':
            # delete this parenthesis (consumes the matching budget)
            dfs(i + 1,
                left - (ch == '('),
                right - (ch == ')'),
                bal,
                path)

        # keep it (letters always take this branch only)
        path.append(ch)
        if ch == '(':
            dfs(i + 1, left, right, bal + 1, path)
        elif ch == ')':
            dfs(i + 1, left, right, bal - 1, path)
        else:
            dfs(i + 1, left, right, bal, path)
        path.pop()

    dfs(0, left_rem, right_rem, 0, [])
    return list(found)
use std::collections::HashSet;

/// How many '(' and ')' must be deleted. One left-to-right scan.
fn min_removals(s: &str) -> (i32, i32) {
    let mut left = 0i32;
    let mut right = 0i32;
    for ch in s.chars() {
        if ch == '(' {
            left += 1;
        } else if ch == ')' {
            if left > 0 {
                left -= 1;
            } else {
                right += 1;
            }
        }
    }
    (left, right)
}

/// Backtrack with an exact deletion budget. Balance never goes negative.
pub fn remove_invalid_dfs(s: &str) -> Vec<String> {
    let chars: Vec<char> = s.chars().collect();
    let (left_rem, right_rem) = min_removals(s);
    let mut found: HashSet<String> = HashSet::new();
    let mut path = String::new();

    fn dfs(
        i: usize,
        left: i32,
        right: i32,
        bal: i32,
        chars: &[char],
        path: &mut String,
        found: &mut HashSet<String>,
    ) {
        if left < 0 || right < 0 || bal < 0 {
            return;
        }
        if i == chars.len() {
            if left == 0 && right == 0 && bal == 0 {
                found.insert(path.clone());
            }
            return;
        }
        let ch = chars[i];
        if ch == '(' || ch == ')' {
            dfs(
                i + 1,
                left - i32::from(ch == '('),
                right - i32::from(ch == ')'),
                bal,
                chars,
                path,
                found,
            );
        }
        path.push(ch);
        let next_bal = match ch {
            '(' => bal + 1,
            ')' => bal - 1,
            _ => bal,
        };
        dfs(i + 1, left, right, next_bal, chars, path, found);
        path.pop();
    }

    dfs(0, left_rem, right_rem, 0, &chars, &mut path, &mut found);
    found.into_iter().collect()
}
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {

    /** How many '(' and ')' must be deleted. One left-to-right scan. */
    private int[] minRemovals(String s) {
        int left = 0, right = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                left++;
            } else if (c == ')') {
                if (left > 0) {
                    left--;
                } else {
                    right++;
                }
            }
        }
        return new int[] {left, right};
    }

    /** Backtrack with an exact deletion budget. Balance never goes negative. */
    public List<String> removeInvalidParenthesesDfs(String s) {
        int[] rem = minRemovals(s);
        Set<String> found = new HashSet<>();
        dfs(s, 0, rem[0], rem[1], 0, new StringBuilder(), found);
        return new ArrayList<>(found);
    }

    private void dfs(String s, int i, int left, int right, int bal,
                     StringBuilder path, Set<String> found) {
        if (left < 0 || right < 0 || bal < 0) {
            return;
        }
        if (i == s.length()) {
            if (left == 0 && right == 0 && bal == 0) {
                found.add(path.toString());
            }
            return;
        }
        char c = s.charAt(i);
        if (c == '(' || c == ')') {
            dfs(s, i + 1, left - (c == '(' ? 1 : 0), right - (c == ')' ? 1 : 0),
                    bal, path, found);
        }
        path.append(c);
        int nextBal = (c == '(') ? bal + 1 : (c == ')') ? bal - 1 : bal;
        dfs(s, i + 1, left, right, nextBal, path, found);
        path.deleteCharAt(path.length() - 1);
    }
}
#include <string>
#include <unordered_set>
#include <utility>
#include <vector>

// How many '(' and ')' must be deleted. One left-to-right scan.
std::pair<int, int> minRemovals(const std::string& s) {
    int left = 0, right = 0;
    for (char c : s) {
        if (c == '(') {
            ++left;
        } else if (c == ')') {
            if (left > 0) {
                --left;
            } else {
                ++right;
            }
        }
    }
    return {left, right};
}

static void dfs(const std::string& s, int i, int left, int right, int bal,
                std::string& path, std::unordered_set<std::string>& found) {
    if (left < 0 || right < 0 || bal < 0) {
        return;
    }
    if (i == static_cast<int>(s.size())) {
        if (left == 0 && right == 0 && bal == 0) {
            found.insert(path);
        }
        return;
    }
    const char c = s[i];
    if (c == '(' || c == ')') {
        dfs(s, i + 1, left - (c == '('), right - (c == ')'), bal, path, found);
    }
    path.push_back(c);
    const int nextBal = (c == '(') ? bal + 1 : (c == ')') ? bal - 1 : bal;
    dfs(s, i + 1, left, right, nextBal, path, found);
    path.pop_back();
}

// Backtrack with an exact deletion budget. Balance never goes negative.
std::vector<std::string> removeInvalidParenthesesDfs(const std::string& s) {
    auto [leftRem, rightRem] = minRemovals(s);
    std::unordered_set<std::string> found;
    std::string path;
    path.reserve(s.size());
    dfs(s, 0, leftRem, rightRem, 0, path, found);
    return {found.begin(), found.end()};
}
Time O(2p)

Still exponential in the number of parentheses, but every path that would over-delete or go negative is cut immediately. Peak recursion depth is n ≤ 25, so the call stack is not a concern.

Space O(n + k)

O(n) for the path and the stack, plus the output set of k answers. No layer of strings lives in a queue. This is the version to write if the interviewer asks about memory.

5. Follow-up discussion if time permits

  • Return any one valid string, not all of them. Then you do not need search at all: scan and delete every ')' that would drive the balance negative, then scan right-to-left and delete leftover '('. O(n) time, one string. Mentioning this without being asked looks like you misread the problem; mentioning it as a follow-up looks like you know the family.
  • Return only the minimum number of deletions. That is exactly left_rem + right_rem from the linear scan in 4.3. No search.
  • Skip consecutive duplicate deletions. When two identical parens sit next to each other, deleting either produces the same neighbour. In BFS you can continue when s[i] == s[i-1] for a parenthesis; in DFS, skip a run with a while-loop. The seen / result set already makes this a speed tweak, not a correctness one.
  • Multiple bracket types. A single integer balance is no longer enough: "([)]" is invalid even though counts match. Neighbour generation is the same, but is_valid needs a stack (or a typed balance). The DFS budget scan also has to track types separately.
  • Why not binary-search the deletion count? “There exists a valid string with at most k deletions” is monotone, so you can binary-search k and DFS at each mid. That is O(log n) times a search you already run once at the true k. Strictly extra work; a fair answer to “any other approach?”
  • Very long n, return all answers. The output size itself can be exponential. If n is 104 the problem statement is wrong; push back and ask whether they want one string or the count.
  • Must the original relative order of letters and kept parens be preserved? Yes — we only delete, we never reorder. If permutations were allowed the problem would be “rearrange plus delete,” which is different.
  • What does “good enough” look like here? Confirm letters stay and empty string is legal, write a correct is_valid, enumerate subsets as the baseline, upgrade to layer-by-layer BFS with a seen set and an early stop, trace "()())()" yourself, and know the linear scan that yields the exact deletion budget if memory comes up.
