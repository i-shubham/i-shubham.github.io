Longest substring without repeating characters

The sliding window poster child — easy to sketch, easy to get the left pointer wrong on repeats.

1. Problem statement & explanation

Given a string s, return the length of the longest substring of s that contains no repeated character.

“Substring” means contiguous. That one word is the whole problem. If it said “subsequence” the answer would just be the count of distinct characters and there would be nothing to discuss. Because it is contiguous, the answer is a window: a pair of indices [left, right] that we slide rightwards over the string.

The property that makes a linear solution possible is monotonicity: if the window [left, right] has all-distinct characters, then every sub-window of it does too. So when adding s[right] breaks the invariant, we never need to move left backwards — a shorter window starting further left could not help. Both pointers only ever move forward, which is what turns O(n²) into O(n).

1.1 Input / output

Signature

contract
length_of_longest_substring(s: str) -> int   # length only, not the substring

Worked examples

example 1 — the standard case
Input:  s = "abcabcbb"
Output: 3
Why:    "abc" (and "bca", "cab") — every longer window repeats a character.
example 2 — all identical
Input:  s = "bbbbb"
Output: 1
Why:    every window of length 2 already repeats. Answer is a single 'b'.
example 3 — the answer is not a prefix
Input:  s = "pwwkew"
Output: 3
Why:    "wke" — not "pwke", which is a subsequence, not a substring.
        This example exists precisely to catch subsequence answers.
example 4 — the left-pointer trap
Input:  s = "abba"
Output: 2
Why:    at right = 3 ('a'), the previous 'a' sits at index 0, which is
        ALREADY BEHIND the window (left = 2). Jumping left back to 1 would
        report "bba" = 3. Wrong. left must never decrease.
example 5 — degenerate inputs
Input:  s = ""     -> Output: 0
Input:  s = " "    -> Output: 1     (space is a character)
Input:  s = "au"   -> Output: 2
Input:  s = "dvdf" -> Output: 3     ("vdf", again a non-prefix answer)

Constraints to state back

  • 0 ≤ s.length ≤ 5 × 10^4 — the empty string is legal and must return 0, not crash.
  • s consists of English letters, digits, symbols and spaces — i.e. printable ASCII, so a 128-slot table is enough and the space term is O(1).
  • Return a length (an int). If the interviewer wants the substring itself, you also need to remember where the best window started — see 4.3.
  • Comparison is exact and case-sensitive: 'a' and 'A' are different characters unless told otherwise.

2. Open questions & clarifications

  • Substring or subsequence? Confirm contiguity explicitly. If it is a subsequence, the answer is len(set(s)) and the interview is over in 20 seconds.
  • What is the alphabet? ASCII-128 → fixed array, O(1) space. Full Unicode → hash map, and the space term becomes O(min(n, Σ)).
  • Length or the substring itself? Returning the substring costs one extra variable (best_start) — cheap, but only if you know up front.
  • Case-sensitive? Is "aA" length 1 or 2? Never assume.
  • Do whitespace and punctuation count as characters? Usually yes; confirm so " " returning 1 is not a surprise.
  • Unicode: code points or grapheme clusters? Is "é" (e + combining accent) one character or two? For emoji with skin-tone modifiers this genuinely changes the answer.
  • Ties — which window do you want? For "abcabc" several windows have length 3. First, last, or any?
  • Is the whole string in memory? A stream still works (the window only ever moves forward) but you cannot return a slice of it without buffering.
  • Expected n? At 5 × 10⁴ even O(n²) passes; if the interviewer says gigabytes, the O(1)-space window is the point.

2.1 Suggestions to the candidate

  • Do not jump straight to “sliding window”. Naming the pattern is not solving the problem. Say what the window maintains (“all characters inside are distinct”) and why left may only move forward. That reasoning is the answer; the name is a label.
  • Do not present the optimal code first. Two minutes on the brute force buys you the observation that every start position re-reads the same characters — and the window solution is then the obvious fix rather than a magic trick.
  • Write "abba" on the board before you code. This is the example that separates a working solution from a plausible-looking one. Deliberately test the last[c] ≥ left guard against it.
  • Choose your window style and stay in it. Either jump left straight to last[c] + 1, or shrink one step at a time with a while loop. Both are correct; mixing them mid-solution is how off-by-ones appear.
  • State the space term precisely. “O(min(n, Σ)) — bounded by 128 for ASCII, so effectively O(1)” reads much better than a vague “O(n) for the map”.
  • Handle the empty string explicitly. Not with a special case if the loop already handles it — just say “the loop body never runs, best stays 0, correct.”
  • Ask about Unicode once, then move on. It shows range. Litigating grapheme clusters for five minutes does not.
  • Trace your own code out loud after writing it. Finding your own off-by-one is a strong positive signal; having it found for you is not.

3. Brute-force approach

Try every start index, extend rightwards while characters stay distinct, and stop the moment one repeats. Correct by construction: it literally examines every candidate window.

  1. For each start i, create an empty set.
  2. Walk j = i, i+1, … adding s[j] to the set.
  3. The instant s[j] is already present, no window starting at i can extend past j — break.
  4. Track the maximum j - i + 1 seen across all starts.
Say this while writing it

The truly naive version is O(n³): enumerate all O(n²) substrings and check each for duplicates in O(n). Reusing the set as j advances already drops that to O(n²). Mention both so the interviewer sees you are optimising, not guessing.

3.1 Code — Python, Rust, Java, C++

def length_of_longest_substring_brute(s: str) -> int:
    """Every start index, extended until a character repeats.

    O(n^2) rather than the fully naive O(n^3), because the `seen` set is
    reused as j advances instead of being rebuilt per substring.
    """
    n = len(s)
    best = 0
    for i in range(n):
        seen = set()
        for j in range(i, n):
            if s[j] in seen:
                break                      # no window from i survives past j
            seen.add(s[j])
            best = max(best, j - i + 1)
    return best                            # s == "" never enters the loop -> 0
use std::collections::HashSet;

/// Every start index, extended until a character repeats.
/// Collects to `Vec<char>` first so indexing is by character, not byte.
pub fn length_of_longest_substring_brute(s: &str) -> usize {
    let chars: Vec<char> = s.chars().collect();
    let mut best = 0usize;

    for i in 0..chars.len() {
        let mut seen: HashSet<char> = HashSet::new();
        for j in i..chars.len() {
            // `insert` returns false when the value was already present.
            if !seen.insert(chars[j]) {
                break;                     // no window from i survives past j
            }
            best = best.max(j - i + 1);
        }
    }
    best
}
import java.util.HashSet;
import java.util.Set;

class Solution {

    /**
     * Every start index, extended until a character repeats.
     * O(n^2), not the fully naive O(n^3): the set is reused as j advances.
     */
    public int lengthOfLongestSubstringBrute(String s) {
        int best = 0;
        for (int i = 0; i < s.length(); i++) {
            Set<Character> seen = new HashSet<>();
            for (int j = i; j < s.length(); j++) {
                // add() returns false when the element was already present.
                if (!seen.add(s.charAt(j))) {
                    break;                 // no window from i survives past j
                }
                best = Math.max(best, j - i + 1);
            }
        }
        return best;
    }
}

// Every start index, extended until a character repeats.
// O(n^2), not the fully naive O(n^3): the set is reused as j advances.
int lengthOfLongestSubstringBrute(const std::string& s) {
    const int n = static_cast<int>(s.size());
    int best = 0;

    for (int i = 0; i < n; ++i) {
        std::unordered_set<char> seen;
        for (int j = i; j < n; ++j) {
            // insert() returns {iterator, inserted?}
            if (!seen.insert(s[j]).second) {
                break;                     // no window from i survives past j
            }
            best = std::max(best, j - i + 1);
        }
    }
    return best;
}

3.2 Complexity

Time O(n²)

Each of n starts scans up to n characters. With a bounded alphabet Σ the inner loop cannot exceed Σ+1 steps, so it is really O(n·Σ) — worth pointing out, it is a genuinely sharper bound.

Space O(min(n, Σ))

One set holding at most Σ distinct characters — at most 128 for ASCII.

Why this is not the final answer

When the window starting at i stops at j because s[j] duplicates s[k] (with i ≤ k < j), we already know that every start in [i, k] will also stop at j. Restarting at i+1 re-derives a fact we hold. Jumping left to k+1 instead skips all of that.

4. Optimised approach

Key insight: keep one window and remember, for every character, the last index at which it appeared. When s[right] repeats a character whose last occurrence is inside the current window, the smallest legal window ending at right starts at last[s[right]] + 1. Jump left there in one step. If the last occurrence is already behind left, it is irrelevant — leave left alone.

  1. last = map from character to its most recent index. left = 0, best = 0.
  2. For right = 0 … n-1, let c = s[right].
  3. If c is in last and last[c] ≥ left, set left = last[c] + 1. The second half of that condition is the entire "abba" fix.
  4. Set last[c] = right.
  5. best = max(best, right - left + 1).
The invariant to say out loud

After processing right, the window s[left .. right] contains no repeats, and it is the longest repeat-free window ending at right. Since the answer is some window ending at some right, taking the max over all right is exhaustive. left is non-decreasing, so the total work is one forward pass.

4.1 Code — Python, Rust, Java, C++

from typing import Dict


def length_of_longest_substring(s: str) -> int:
    """Sliding window with last-seen indices. One forward pass.

    Invariant: after each step, s[left:right+1] is the longest repeat-free
    window that ends at `right`. `left` never decreases.
    """
    last: Dict[str, int] = {}              # character -> last index seen
    left = 0
    best = 0

    for right, ch in enumerate(s):
        prev = last.get(ch, -1)
        if prev >= left:                   # the repeat is INSIDE the window
            left = prev + 1                # jump past it in one move
        last[ch] = right
        best = max(best, right - left + 1)

    return best
use std::collections::HashMap;

/// Sliding window with last-seen indices. One forward pass.
///
/// Invariant: after each step, the window `[left, right]` is the longest
/// repeat-free window ending at `right`. `left` never decreases.
///
/// Indices are signed so the "never seen" sentinel (-1) compares correctly.
pub fn length_of_longest_substring(s: &str) -> usize {
    let mut last: HashMap<char, i64> = HashMap::new();
    let mut left: i64 = 0;
    let mut best: i64 = 0;

    for (right, ch) in s.chars().enumerate() {
        let right = right as i64;
        let prev = *last.get(&ch).unwrap_or(&-1);
        if prev >= left {                  // the repeat is INSIDE the window
            left = prev + 1;               // jump past it in one move
        }
        last.insert(ch, right);
        best = best.max(right - left + 1);
    }
    best as usize
}
import java.util.HashMap;
import java.util.Map;

class Solution {

    /**
     * Sliding window with last-seen indices. One forward pass.
     *
     * Invariant: after each step, s[left .. right] is the longest
     * repeat-free window ending at `right`. `left` never decreases.
     */
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> last = new HashMap<>();
        int left = 0;
        int best = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            int prev = last.getOrDefault(c, -1);
            if (prev >= left) {            // the repeat is INSIDE the window
                left = prev + 1;           // jump past it in one move
            }
            last.put(c, right);
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}

#include <string>
#include <unordered_map>

// Sliding window with last-seen indices. One forward pass.
//
// Invariant: after each step, s[left .. right] is the longest repeat-free
// window ending at `right`. `left` never decreases.
int lengthOfLongestSubstring(const std::string& s) {
    std::unordered_map<char, int> last;    // character -> last index seen
    int left = 0;
    int best = 0;

    for (int right = 0; right < static_cast<int>(s.size()); ++right) {
        const char c = s[right];
        auto it = last.find(c);
        const int prev = (it == last.end()) ? -1 : it->second;
        if (prev >= left) {                // the repeat is INSIDE the window
            left = prev + 1;               // jump past it in one move
        }
        last[c] = right;
        best = std::max(best, right - left + 1);
    }
    return best;
}

4.2 Complexity

Time O(n)

Exactly one iteration per character; left only moves forward, so the pointers travel at most 2n steps in total. No inner loop, no rescans.

Space O(min(n, Σ))

One entry per distinct character. With the stated ASCII alphabet that is at most 128 entries — constant.

Edge cases this version already handles

"" → 0 (loop body never runs). " " → 1. "bbbb" → 1. "abba" → 2 via the prev ≥ left guard. "dvdf" → 3. A string of 128 distinct ASCII characters → 128.

4.3 Variant: return the substring, O(1) space

Two upgrades the interviewer often asks for next, both cheap. First, remember best_start alongside best_len so you can slice out the actual substring. Second, since the alphabet is bounded, replace the hash map with a flat array indexed by character code — strictly O(1) space, and materially faster because there is no hashing and no pointer chasing.

ALPHABET = 128                             # printable ASCII, per the constraints


def longest_unique_substring(s: str) -> str:
    """Same window, but on a flat table, and returns the substring itself.

    Precondition: every character satisfies ord(ch) < ALPHABET.
    """
    last = [-1] * ALPHABET                 # code point -> last index seen
    left = 0
    best_len = 0
    best_start = 0

    for right, ch in enumerate(s):
        c = ord(ch)
        if last[c] >= left:
            left = last[c] + 1
        last[c] = right
        if right - left + 1 > best_len:    # strict > keeps the FIRST best window
            best_len = right - left + 1
            best_start = left

    return s[best_start:best_start + best_len]
/// Same window on a flat 256-slot byte table, returning a borrowed slice.
///
/// Byte-indexed, so this is correct for ASCII input. For multi-byte UTF-8
/// keep the `HashMap<char, _>` version in 4.1 instead.
pub fn longest_unique_substring(s: &str) -> &str {
    let bytes = s.as_bytes();
    let mut last = [-1i64; 256];           // byte value -> last index seen
    let mut left: i64 = 0;
    let mut best_len: i64 = 0;
    let mut best_start: i64 = 0;

    for (right, &b) in bytes.iter().enumerate() {
        let right = right as i64;
        let c = b as usize;
        if last[c] >= left {
            left = last[c] + 1;
        }
        last[c] = right;
        if right - left + 1 > best_len {   // strict >: keep the FIRST best window
            best_len = right - left + 1;
            best_start = left;
        }
    }
    &s[best_start as usize..(best_start + best_len) as usize]
}
import java.util.Arrays;

class Solution {

    private static final int ALPHABET = 128;   // printable ASCII

    /**
     * Same window on a flat table, returning the substring itself.
     * Precondition: every char is below ALPHABET.
     */
    public String longestUniqueSubstring(String s) {
        int[] last = new int[ALPHABET];
        Arrays.fill(last, -1);                 // -1 = never seen

        int left = 0, bestLen = 0, bestStart = 0;
        for (int right = 0; right < s.length(); right++) {
            int c = s.charAt(right);
            if (last[c] >= left) {
                left = last[c] + 1;
            }
            last[c] = right;
            if (right - left + 1 > bestLen) {  // strict >: keep FIRST best window
                bestLen = right - left + 1;
                bestStart = left;
            }
        }
        return s.substring(bestStart, bestStart + bestLen);
    }
}

#include <string>

// Same window on a flat 256-slot byte table, returning the substring.
// Indexed through unsigned char so a negative signed char cannot escape
// the array (a real portability bug on platforms where char is signed).
std::string longestUniqueSubstring(const std::string& s) {
    std::array<int, 256> last{};
    last.fill(-1);                             // -1 = never seen

    int left = 0, bestLen = 0, bestStart = 0;
    for (int right = 0; right < static_cast<int>(s.size()); ++right) {
        const auto c = static_cast<unsigned char>(s[right]);
        if (last[c] >= left) {
            left = last[c] + 1;
        }
        last[c] = right;
        if (right - left + 1 > bestLen) {      // strict >: keep FIRST best window
            bestLen = right - left + 1;
            bestStart = left;
        }
    }
    return s.substr(bestStart, bestLen);
}
Time O(n)

Identical pass, minus the hashing. Typically 2–4× faster in practice on ASCII input.

Space O(Σ) = O(1)

A fixed 128- or 256-slot table regardless of input size. The returned substring is O(n) only if you copy it — Rust returns a borrow.

5. Follow-up discussion if time permits

  • Longest substring with at most k distinct characters. Same window, but the invariant becomes a size bound on a count map, so left advances in a while loop that decrements counts. This is the generalisation — our problem is the case “every count ≤ 1”.
  • Longest substring with at most k repeats of any character (character replacement). Window where window_len - max_count ≤ k. Worth discussing because the max_count trick means you never have to shrink max_count back down.
  • Shortest substring containing every character of another string (minimum window substring). Same two-pointer skeleton, inverted objective: grow until valid, then shrink while still valid. Note the direction flips — here we shrink while invalid, there we shrink while valid.
  • Full Unicode input. Iterate over code points, not bytes (an ASCII byte table silently mis-slices UTF-8). If graphemes are the unit, segment first with ICU or unicode-segmentation and run the same window over the cluster list.
  • Streaming input, unbounded length. The window works unchanged since both pointers move forward, but returning the substring requires buffering the last Σ+1 characters — note that the buffer is bounded by the alphabet, not by n.
  • All maximal repeat-free windows, not just the longest. Emit a window each time left jumps. Output size is O(n) windows.
  • Parallel / chunked. Split the string into chunks, solve each, then fix up windows that straddle a boundary by re-scanning only Σ characters either side. Map-reduce friendly and worth a sentence for large-scale roles.
  • Why can't we binary-search the answer length? Because “there exists a repeat-free window of length L” is monotone in L, you actually can — check with a fixed-size window scan in O(n) per L, giving O(n log n). Strictly worse than O(n), but a good answer to “can you think of another way?”
  • What does “good enough” look like here? Confirm substring-not-subsequence, state and discard the O(n²) baseline, write the window with the prev ≥ left guard correct on the first attempt, trace "abba" yourself, and quantify space as O(min(n, Σ)).
