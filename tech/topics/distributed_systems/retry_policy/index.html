Build a retry policy that does not amplify outages

Retries without jitter turn a blip into a self-DDoS — the outage amplifier pattern.

60-minute agenda

How I'd open the discussion

The first thing I'd establish is that retries are a double-edged sword. A single client retrying a transient 503 is fine. But when 10 000 clients all retry at the same time — with the same backoff interval — you get a synchronized thundering herd that's worse than the original failure. I've seen a 2-second blip turn into a 20-minute outage because every retry wave arrived in a synchronized spike.

The fix has three layers. First, exponential backoff with full jitter: instead of retrying at exactly 1 s, 2 s, 4 s, each client picks uniformly at random from [0, 2^attempt × base]. This spreads the retry load across time. Second, a retry budget: each client gets, say, 10% of its request volume as retries per 10-second window. Once exhausted, it stops retrying and fails fast. Third, a circuit breaker: if the error rate exceeds a threshold (e.g., 50% over 20 requests), the circuit opens and all requests fail immediately for a cooldown period.

These three together mean: individual transient failures get retried with spread-out timing, widespread failures get capped by the budget, and sustained failures trigger a fast-fail circuit that lets the downstream service recover.

Open questions worth asking

  • What transport — HTTP, gRPC, message queue?
  • Which errors are retryable — 5xx only, or also timeouts and connection resets?
  • Is the operation idempotent? Can we safely retry a POST?
  • What is the acceptable end-to-end latency budget?
  • How many concurrent clients call this service?
  • Is there a service mesh (Envoy, Istio) that handles retries at the infra level?
  • Do we need per-endpoint or global retry budgets?
  • What is the downstream service's recovery time after overload?
  • Are there dependent services that also retry — amplification chains?
  • Do we have metrics on current retry rates and error rates?

Scope I'd lock first

  • In: exponential backoff + jitter, retry budgets, circuit breaker, observability.
  • Out: service mesh configuration, load shedding on the server side.
  • Stretch: compare retry amplification across a 3-tier call chain.

Approach / design notes

Start with the failure taxonomy: transient errors (503, timeout, connection reset) are retryable. Permanent errors (400, 404, 422) are not. This distinction is critical — retrying a 400 is pointless and wastes budget.

Exponential backoff: delay = base × 2^attempt. Without jitter, 1000 clients that failed at t=0 all retry at t=100ms, then t=200ms, then t=400ms — synchronized waves. Full jitter: delay = random(0, base × 2^attempt). This spreads the retries uniformly across the backoff window. The AWS architecture blog showed that full jitter produces the fewest total calls and fastest completion time compared to equal jitter or decorrelated jitter.

Retry budget: each client tracks retries in a sliding window (e.g., 10 seconds). The budget is 10% of normal request volume. At 200 RPS baseline, the client gets 20 retries per window. Once exhausted, all requests fail fast with a clear error: 'retry budget exhausted.' This prevents a broken downstream from consuming unbounded retry traffic.

Circuit breaker: tracks success/failure ratio over the last N requests. When failures exceed the threshold (e.g., 50%), the circuit opens — all requests fail immediately without hitting the downstream. After a cooldown (30 s), the circuit moves to half-open: one probe request is allowed through. If it succeeds, the circuit closes. If it fails, back to open.

The three mechanisms compose: jitter prevents synchronization, budgets cap volume, and the circuit breaker stops all traffic during sustained failures. Together, they turn retries from an outage amplifier into a controlled recovery mechanism.

Deep dive (spend 15–25 minutes here)

Jitter math: with full jitter, delay = uniform(0, min(cap, base × 2^attempt)). For base=100 ms and cap=10 s: attempt 0 → [0, 100 ms], attempt 1 → [0, 200 ms], attempt 2 → [0, 400 ms], attempt 6 → [0, 6400 ms], attempt 7+ → [0, 10 000 ms]. The expected delay is half the upper bound. Over 1000 clients, retries at attempt 2 spread uniformly over a 400 ms window instead of all hitting at exactly 400 ms.

Retry budget implementation: use a token bucket. Initialize with 20 tokens. Refill at 2 tokens/second (= 20 per 10 s window). Each retry consumes 1 token. If tokens = 0, reject the retry. This is simpler than tracking a sliding window and gives smooth behavior across window boundaries. The refill rate = budget_cap / window_seconds.

Circuit breaker edge cases: the half-open state is the trickiest. If you allow only one probe and it times out (30 s), the circuit stays open for another 30 s — total 60 s of downtime for a service that recovered at t=31 s. Better: allow 3 probes in half-open, require 2/3 success to close. This reduces false-open duration. But too many probes can overload a recovering service. Tune probe count to ~1% of normal traffic.

Amplification chains: service A retries 3× to B, B retries 3× to C. A single failure at C generates 3 calls from B, which generates 9 calls from A. With 3 tiers, that's 27× amplification. The fix: retry budgets at each layer, and ideally only retry at the layer closest to the failure. Mark errors as retryable-by-caller or already-retried in the response so upstream callers don't double-retry.

Observability: emit these metrics per service call: retry_attempt (counter, tagged by attempt number), retry_budget_remaining (gauge), circuit_state (gauge — 0=closed, 1=half-open, 2=open), retry_delay_ms (histogram). Alert on budget_remaining = 0 sustained for > 1 minute — that means a downstream is consistently failing and retries are exhausted.

Retry decorator with jitter, budget, and circuit breaker

import time, random, functools
from collections import deque

class CircuitBreaker:
    def __init__(self, threshold=0.5, window=20, cooldown_s=30):
        self.threshold = threshold
        self.window = window
        self.cooldown_s = cooldown_s
        self.results = deque(maxlen=window)
        self.state = 'closed'
        self.opened_at = 0.0

    def allow(self) -> bool:
        if self.state == 'closed':
            return True
        if self.state == 'open':
            if time.monotonic() - self.opened_at >= self.cooldown_s:
                self.state = 'half_open'
                return True
            return False
        return True  # half_open: allow probe

    def record(self, success: bool):
        self.results.append(success)
        if self.state == 'half_open':
            self.state = 'closed' if success else 'open'
            if not success:
                self.opened_at = time.monotonic()
            return
        if len(self.results) >= self.window:
            fail_rate = 1 - sum(self.results) / len(self.results)
            if fail_rate >= self.threshold:
                self.state = 'open'
                self.opened_at = time.monotonic()


class RetryBudget:
    def __init__(self, cap=20, window_s=10):
        self.tokens = float(cap)
        self.refill_rate = cap / window_s
        self.last_refill = time.monotonic()
        self.cap = cap

    def acquire(self) -> bool:
        now = time.monotonic()
        self.tokens = min(self.cap, self.tokens + (now - self.last_refill) * self.refill_rate)
        self.last_refill = now
        if self.tokens >= 1:
            self.tokens -= 1
            return True
        return False


def retry(max_attempts=3, base_ms=100, cap_ms=10000,
          retryable=(Exception,), breaker=None, budget=None):
    def decorator(fn):
        @functools.wraps(fn)
        def wrapper(*a, **kw):
            for attempt in range(max_attempts):
                if breaker and not breaker.allow():
                    raise RuntimeError('circuit open')
                try:
                    result = fn(*a, **kw)
                    if breaker:
                        breaker.record(True)
                    return result
                except retryable as exc:
                    if breaker:
                        breaker.record(False)
                    if attempt == max_attempts - 1:
                        raise
                    if budget and not budget.acquire():
                        raise RuntimeError('retry budget exhausted') from exc
                    delay = random.uniform(0, min(cap_ms, base_ms * 2 ** attempt)) / 1000
                    time.sleep(delay)
        return wrapper
    return decorator
use std::collections::VecDeque;
use std::time::{Duration, Instant};
use rand::Rng;

// ── Circuit breaker ──────────────────────────────────────────────────

#[derive(Debug, PartialEq)]
enum CBState { Closed, Open, HalfOpen }

pub struct CircuitBreaker {
    threshold: f64,
    window: usize,
    cooldown: Duration,
    results: VecDeque<bool>,
    state: CBState,
    opened_at: Instant,
}

impl CircuitBreaker {
    pub fn new(threshold: f64, window: usize, cooldown_s: u64) -> Self {
        Self {
            threshold, window,
            cooldown: Duration::from_secs(cooldown_s),
            results: VecDeque::with_capacity(window),
            state: CBState::Closed,
            opened_at: Instant::now(),
        }
    }

    pub fn allow(&mut self) -> bool {
        match self.state {
            CBState::Closed => true,
            CBState::Open => {
                if self.opened_at.elapsed() >= self.cooldown {
                    self.state = CBState::HalfOpen;
                    true
                } else { false }
            }
            CBState::HalfOpen => true, // allow probe
        }
    }

    pub fn record(&mut self, success: bool) {
        if self.results.len() >= self.window { self.results.pop_front(); }
        self.results.push_back(success);

        if self.state == CBState::HalfOpen {
            self.state = if success { CBState::Closed } else { CBState::Open };
            if !success { self.opened_at = Instant::now(); }
            return;
        }
        if self.results.len() >= self.window {
            let ok: usize = self.results.iter().filter(|&&s| s).count();
            let fail_rate = 1.0 - (ok as f64 / self.results.len() as f64);
            if fail_rate >= self.threshold {
                self.state = CBState::Open;
                self.opened_at = Instant::now();
            }
        }
    }
}

// ── Token-bucket retry budget ────────────────────────────────────────

pub struct RetryBudget {
    tokens: f64,
    cap: f64,
    refill_rate: f64,
    last_refill: Instant,
}

impl RetryBudget {
    pub fn new(cap: f64, window_s: f64) -> Self {
        Self { tokens: cap, cap, refill_rate: cap / window_s, last_refill: Instant::now() }
    }

    pub fn acquire(&mut self) -> bool {
        let now = Instant::now();
        self.tokens = (self.tokens + now.duration_since(self.last_refill).as_secs_f64()
                       * self.refill_rate).min(self.cap);
        self.last_refill = now;
        if self.tokens >= 1.0 { self.tokens -= 1.0; true } else { false }
    }
}

// ── Generic retry with jitter ────────────────────────────────────────

pub fn retry<F, T, E>(
    max_attempts: usize,
    base_ms: u64,
    cap_ms: u64,
    breaker: Option<&mut CircuitBreaker>,
    budget: Option<&mut RetryBudget>,
    mut f: F,
) -> Result<T, E>
where
    F: FnMut() -> Result<T, E>,
    E: std::fmt::Debug,
{
    let mut rng = rand::thread_rng();
    for attempt in 0..max_attempts {
        if let Some(cb) = breaker.as_deref_mut() {
            if !cb.allow() { panic!("circuit open"); }
        }
        match f() {
            Ok(v) => {
                if let Some(cb) = breaker.as_deref_mut() { cb.record(true); }
                return Ok(v);
            }
            Err(e) => {
                if let Some(cb) = breaker.as_deref_mut() { cb.record(false); }
                if attempt == max_attempts - 1 { return Err(e); }
                if let Some(rb) = budget.as_deref_mut() {
                    if !rb.acquire() { panic!("retry budget exhausted"); }
                }
                let delay = rng.gen_range(0..=cap_ms.min(base_ms * 2u64.pow(attempt as u32)));
                std::thread::sleep(Duration::from_millis(delay));
            }
        }
    }
    unreachable!()
}

// ── Circuit breaker ──────────────────────────────────────────────────

typedef NS_ENUM(NSInteger, CBState) {
    CBStateClosed, CBStateOpen, CBStateHalfOpen
};

@interface CircuitBreaker : NSObject {
    double _threshold;
    NSUInteger _window;
    double _cooldownS;
    std::deque<bool> _results;
    CBState _state;
    std::chrono::steady_clock::time_point _openedAt;
}
- (instancetype)initWithThreshold:(double)thr window:(NSUInteger)w cooldown:(double)s;
- (BOOL)allow;
- (void)record:(BOOL)success;
@end

@implementation CircuitBreaker
- (instancetype)initWithThreshold:(double)thr window:(NSUInteger)w cooldown:(double)s {
    if ((self = [super init])) {
        _threshold = thr; _window = w; _cooldownS = s;
        _state = CBStateClosed;
        _openedAt = std::chrono::steady_clock::now();
    }
    return self;
}

- (BOOL)allow {
    if (_state == CBStateClosed) return YES;
    if (_state == CBStateOpen) {
        auto elapsed = std::chrono::steady_clock::now() - _openedAt;
        if (std::chrono::duration<double>(elapsed).count() >= _cooldownS) {
            _state = CBStateHalfOpen;
            return YES;
        }
        return NO;
    }
    return YES; // half-open probe
}

- (void)record:(BOOL)success {
    if (_results.size() >= _window) _results.pop_front();
    _results.push_back(success);

    if (_state == CBStateHalfOpen) {
        _state = success ? CBStateClosed : CBStateOpen;
        if (!success) _openedAt = std::chrono::steady_clock::now();
        return;
    }
    if (_results.size() >= _window) {
        int ok = 0;
        for (bool s : _results) ok += s;
        double failRate = 1.0 - (double)ok / _results.size();
        if (failRate >= _threshold) {
            _state = CBStateOpen;
            _openedAt = std::chrono::steady_clock::now();
        }
    }
}
@end

// ── Token-bucket retry budget ────────────────────────────────────────

@interface RetryBudget : NSObject {
    double _tokens, _cap, _refillRate;
    std::chrono::steady_clock::time_point _lastRefill;
}
- (instancetype)initWithCap:(double)cap windowS:(double)ws;
- (BOOL)acquire;
@end

@implementation RetryBudget
- (instancetype)initWithCap:(double)cap windowS:(double)ws {
    if ((self = [super init])) {
        _tokens = cap; _cap = cap; _refillRate = cap / ws;
        _lastRefill = std::chrono::steady_clock::now();
    }
    return self;
}

- (BOOL)acquire {
    auto now = std::chrono::steady_clock::now();
    double elapsed = std::chrono::duration<double>(now - _lastRefill).count();
    _tokens = std::fmin(_cap, _tokens + elapsed * _refillRate);
    _lastRefill = now;
    if (_tokens >= 1.0) { _tokens -= 1.0; return YES; }
    return NO;
}
@end

// ── Block-based retry with jitter ────────────────────────────────────

typedef id (^RetryBlock)(void);

static id retryWithBlock(RetryBlock block, int maxAttempts,
                         double baseMs, double capMs,
                         CircuitBreaker *breaker, RetryBudget *budget) {
    for (int attempt = 0; attempt < maxAttempts; ++attempt) {
        if (breaker && ![breaker allow])
            @throw [NSException exceptionWithName:@"CircuitOpen"
                                           reason:@"circuit open" userInfo:nil];
        @try {
            id result = block();
            if (breaker) [breaker record:YES];
            return result;
        } @catch (NSException *exc) {
            if (breaker) [breaker record:NO];
            if (attempt == maxAttempts - 1) @throw;
            if (budget && ![budget acquire])
                @throw [NSException exceptionWithName:@"BudgetExhausted"
                                               reason:@"retry budget exhausted"
                                             userInfo:nil];
            double delay = ((double)arc4random() / UINT32_MAX)
                         * std::fmin(capMs, baseMs * std::pow(2, attempt));
            std::this_thread::sleep_for(
                std::chrono::milliseconds((int64_t)delay));
        }
    }
    return nil;
}

Request path / sequence

Trade-offs I'd say out loud

Full jitter vs equal jitter

Full jitter has lower total load but higher variance in individual delays; equal jitter has a guaranteed minimum delay.

Retry budget scope

Per-client budgets prevent local amplification; global budgets require coordination but give better system-wide protection.

Circuit breaker window size

Small window (10 requests) is responsive but noisy; large window (100) is stable but slow to trip.

Retrying at source vs closest layer

Source retries are simplest but amplify through layers; closest-layer retries minimize total calls.

Where it usually breaks

  • Fixed-interval retries without jitter — synchronized thundering herd after a blip.
  • No retry budget — a broken dependency consumes unbounded retry traffic.
  • Retrying non-idempotent operations — double-charging, duplicate writes.
  • Circuit breaker window too small — noisy state flapping between open and closed.
  • Not distinguishing transient from permanent errors — wasting retries on 400s.
  • Amplification chains: 3 layers × 3 retries = 27× load on the bottom service.
  • Retry delay longer than client timeout — retry completes but client already gave up.
